# 视觉规范（草案 v0.1，D-05）

> 状态：**草案（2026-08-09，讨论中）**。第 1 批（设计批）D-05。
> 原则：作业系统优先"可读、可扫、防错"，不做装饰性设计；Web 与 PDA 两套基线。

## 一、设计 Token

| Token | 值（建议） | 用途 |
|---|---|---|
| 主色 | 靛蓝 indigo | 主操作、选中态 |
| 成功 | emerald | 可用、成功反馈 |
| 待检 | amber | 待检状态 |
| 冻结 | sky | 冻结状态 |
| 异常/危险 | red | 错误、拦截、删除 |
| 中性 | slate 灰阶 | 背景/文字/边框 |
| 字体 | 系统字体栈 + 等宽数字（tabular-nums） | 数量/单号 |
| 圆角 | 中（8-12px Web）/ 大（12-16px PDA） | 触控友好 |
| 间距 | 4 的倍数 | 统一 |

## 二、Web 基线

- 中密度表格、卡片化区块、左侧菜单 + 顶部上下文。
- 状态用徽章（badge）+ 语义色；数量用等宽数字。
- 交互：Dialog 表单、AlertDialog 删除确认、toast 反馈。
- 避免：装饰性渐变、过度阴影、大 KPI 花哨动效。

## 三、PDA 基线

- **大触控**：按钮/输入 ≥48px、间距宽、防误触。
- **高对比**：大字体、深色文字/浅色背景（或深色主题），光照下可读。
- **声音反馈**：成功短音+绿、失败长音+红、可调音量。
- **一屏一任务**：顶部上下文（单号/仓库）、底部主操作按钮固定、拇指区操作。
- **扫码优先**：扫码框常驻聚焦，扫到即处理。

## 四、组件风格（沿用 shadcn 基调 + 语义色）

按钮 / 卡片 / 表格 / 徽章 / Dialog / AlertDialog / toast 按 shadcn 默认形态，仅替换语义色 token。

## 五、待确认

2. PDA 深色主题还是浅色主题？建议浅色高对比（仓库光线复杂时更清晰），暗色后置。
