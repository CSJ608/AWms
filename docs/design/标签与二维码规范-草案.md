# 物料标签与二维码规范（已定稿 v0.4）

> 状态：**已定稿 v0.5（2026-08-10 修订，用户确认）**。批次号格式见通用规范 2.9。解析规则将在契约批（第 2 批）进入 docs/api/，打印端与 PDA 扫码端共同遵守。
> v0.4 更新：供应商外标签示例补全 rt/rc/rb/pd；rt 取值确认（S=供应商 / W=生产车间）；全部开放问题关闭。

## 一、二维码要回答的问题

扫码后系统应能回答：

1. 这是什么物料？（必答）
2. 它是唯一个体吗？（唯一码 vs 非唯一码）
3. 它是谁给的？（来源类型+来源代码 → 系统查名称）
4. 它带有哪些批次信息？（来源批号/生产日期/效期）
5. 这是哪一类标签？（外标签/唯一码标签/批次标签/单据二维码）

## 二、标签类型与码类型

| 标签 | 打印时机 | 码类型 | 用途 |
|---|---|---|---|
| 外标签（SKU 标签） | 收货前（仓库预贴 / 生产部门打印） | 非唯一 | 场景 3/4 扫料 |
| 唯一码标签 | 收货前（仓库预贴） | 唯一 | 逐件/逐箱收货、防重 |
| 批次标签 | 收货后（批控物料） | 非唯一 | 批次追溯 + 库位标识 |
| 单据二维码 | 预建单时 | — | 场景 2/4 打开单据 |

## 三、编码格式（已确认）

- **内容 = `AWMS1:` 前缀 + 紧凑 JSON**（UTF-8，短键名，无空格）。
- 示例：
  - 外标签（供应商，来源信息完整）：`AWMS1:{"v":1,"t":"S","s":"MAT-001","rt":"S","rc":"SUP-001","rb":"SUP-BATCH-01","pd":"2026-08-01"}`
  - 外标签（供应商，仅物料，其余未知）：`AWMS1:{"v":1,"t":"S","s":"MAT-001","rt":"S","rc":"SUP-001"}`
  - 外标签（生产入库）：`AWMS1:{"v":1,"t":"S","s":"MAT-001","rt":"W","rc":"WS-01","rb":"PRD-260809-01","pd":"2026-08-09"}`
  - 唯一码标签：`AWMS1:{"v":1,"t":"U","s":"MAT-001","u":"BOX-260809-001","q":1}`
  - 批次标签：`AWMS1:{"v":1,"t":"B","s":"MAT-001","b":"260810001","q":50}`
  - 单据二维码：`AWMS1:{"v":1,"t":"D","ty":"PO","d":"PO-260809-001","wh":"WH-01"}`
- **供应商外标签建议携带 rt=S + rc（来源代码）；rb（来源批号）、pd（生产日期）可选，有则带**。
- 理由：可扩展（v 版本 + 解析器忽略未知字段）、易解析、QR 容量足够；前缀用于与供应商条码/GS1 区分。
- 二维码纠错级别：M；内容控制短小以保证远距离可扫。

## 四、字段定义

| 字段 | 键 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| 版本 | v | 是 | 规范版本，当前 1 | 1 |
| 标签类型 | t | 是 | S=外标签 / U=唯一码标签 / B=批次标签 / D=单据二维码 | S |
| 物料编码 | s | S/U/B 必填 | 系统内物料编码 | MAT-001 |
| 唯一码 | u | U 必填 | 每件/每箱唯一 | BOX-260809-001 |
| 内部批次号 | b | B 必填 | 收货时生成的内部批次（格式见通用规范 2.9） | 260810001 |
| 来源类型 | rt | 可选 | **S=供应商 / W=生产车间**（可扩展）；与 rc 成对 | S |
| 来源代码 | rc | 可选 | 供应商代码或生产车间代码；**系统按 rt+rc 查名称显示，二维码不存名称** | SUP-001 |
| 来源批号 | rb | 可选 | 供应商批次号或生产批号（对方那边的批号），扫入留档 | SUP-BATCH-01 |
| 生产日期 | pd | 可选 | ISO yyyy-MM-dd | 2026-08-01 |
| 效期 | ex | 可选 | ISO yyyy-MM-dd | 2026-12-31 |
| 数量 | q | 可选 | 标签含数量时；decimal(18,4) | 50 |
| 单据类型 | ty | D 必填 | PO=采购入库 / PR=生产入库 / OT=其他入库 | PO |
| 单据号 | d | D 必填 | 预建单据编号 | PO-260809-001 |
| 仓库编码 | wh | D 可选 | 预建单据所属仓库 | WH-01 |

**明确不入码**（均由系统查询/关联，打印可读文字时显示）：

- 供应商名称（由 rt=S + rc 查供应商主数据）
- 生产车间名称（由 rt=W + rc 查车间/来源主数据）
- 物料名称（由 s 查物料主数据）

**约束矩阵**：

| t | 必填 | 说明 |
|---|---|---|
| S | v,t,s | 外标签：保证"这是什么物料"；建议带 rt/rc；可带 rb/pd/ex/q |
| U | v,t,s,u | 唯一码标签：扫码=物料+唯一个体 |
| B | v,t,s,b,q | 批次标签：扫码=物料+内部批次+数量 |
| D | v,t,ty,d | 单据二维码：扫码按"类型+单号"打开单据 |

## 五、来源与单据类型的说明（2026-08-09 确认）

**ty 是"入库单据类型"，与"标签类型 t"是两回事。**

| 场景 | 单据类型 ty | 标签处理 |
|---|---|---|
| 采购到货 | PO | 供应商自带标签扫入留档；无标签则仓库预贴外标签（rt=S+rc，rb/pd 可选） |
| 生产入库（含生产退料） | PR | 生产部门打印外标签（rt=W+rc+rb+pd）；**生产退料时原标签（t=B 批次标签）若完好，复用/重打原标签，系统识别原内部批次则复用批次**；无标签则手选，收货时生成新内部批次 |
| 盘点发现的物料 | OT | 一般无标签，手选入库；需要时收货后打批次标签 |
| 仓库内调拨 | 不是入库 | 移库/调拨，标签不换，不产生收货 |
| 跨公司调拨 | 走采购流程（PO） | 换标签（按采购收货处理） |

**rt/rc（是谁给的）与 rb（对方那边的批号）与 pd（生产日期）三者互补，可同时存在。**

## 六、PDA 解析行为

| 扫到 | 行为 |
|---|---|
| AWMS1: t=S | 定位物料 → 数量输入/连扫累加；rt/rc 查来源名称显示；rb/pd/ex 扫入留档为批次属性 |
| AWMS1: t=U | 定位物料+唯一个体；在单据行唯一码清单内 → 勾销（重复扫=拦截）；不在清单 → 提示"不在本单" |
| AWMS1: t=B | 定位物料+内部批次 → 数量自动带出；**生产退料场景若批次已存在则复用批次** |
| AWMS1: t=D | 按"单据类型 ty + 单据号 d"路由到单据服务，打开预建单据（统一表，见 ADR-003） |
| 外部条码 | 尽力解析 SKU/批次/日期（EAN/Code128/GS1 AI）→ 留档；解析不出 → 手动录入兜底 |

## 七、打印版式（已确认）

- 二维码（纠错 M）+ 下方**人类可读文字**：物料编码/名称/批次/数量/日期/来源名称（扫码以外的可读性）。
- 批次标签可加"建议库位"文字（不入码，库位会变）。
