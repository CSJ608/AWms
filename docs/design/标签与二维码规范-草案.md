# 物料标签与二维码规范（草案 v0.2）

> 状态：**草案 v0.2（2026-08-09，讨论中）**，第 1 批（设计批）。
> v0.2 更新：新增"来源批号 rb"（供应商批次/生产批号统一）、供应商名称不入码、内部生产入库标签策略、单据二维码带单据类型 ty。
> 范围：AWms 自己打印的物料标签二维码；供应商/外部条码走通用解析兜底（EAN/Code128/GS1 AI），解析不出则手动录入。
> 落地时，本规范的**解析规则**作为契约进入 docs/api/（打印端与 PDA 扫码端共同遵守）。

## 一、二维码要回答的问题

扫码后系统应能回答：

1. 这是什么物料？（必答）
2. 它是唯一个体吗？（唯一码 vs 非唯一码）
3. 它带有哪些附加信息？（来源批号/生产日期/效期/数量）
4. 这是哪一类标签？（外标签/唯一码标签/批次标签/单据二维码）

## 二、标签类型与码类型

| 标签 | 打印时机 | 码类型 | 用途 |
|---|---|---|---|
| 外标签（SKU 标签） | 收货前（仓库预贴 / 生产部门打印） | 非唯一 | 场景 3/4 扫料 |
| 唯一码标签 | 收货前（仓库预贴） | 唯一 | 逐件/逐箱收货、防重 |
| 批次标签 | 收货后（批控物料） | 非唯一 | 批次追溯 + 库位标识 |
| 单据二维码 | 预建单时 | — | 场景 2/4 打开单据 |

## 三、编码格式（已确认）

- **内容 = `AWMS1:` 前缀 + 紧凑 JSON**（UTF-8，短键名，无空格）。
- 示例：
  - 外标签（仓库）：`AWMS1:{"v":1,"t":"S","s":"MAT-001"}`
  - 外标签（含来源信息）：`AWMS1:{"v":1,"t":"S","s":"MAT-001","rb":"SUP-BATCH-01","pd":"2026-08-01"}`
  - 唯一码标签：`AWMS1:{"v":1,"t":"U","s":"MAT-001","u":"BOX-260809-001","q":1}`
  - 批次标签：`AWMS1:{"v":1,"t":"B","s":"MAT-001","b":"B260809-001","q":50}`
  - 单据二维码：`AWMS1:{"v":1,"t":"D","ty":"PO","d":"PO-260809-001","wh":"WH-01"}`
- 理由：可扩展（v 版本 + 解析器忽略未知字段）、易解析、QR 容量足够；前缀用于与供应商条码/GS1 区分。
- 二维码纠错级别：M；内容控制短小以保证远距离可扫。

## 四、字段定义

| 字段 | 键 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| 版本 | v | 是 | 规范版本，当前 1 | 1 |
| 标签类型 | t | 是 | S=外标签 / U=唯一码标签 / B=批次标签 / D=单据二维码 | S |
| 物料编码 | s | S/U/B 必填 | 系统内物料编码 | MAT-001 |
| 唯一码 | u | U 必填 | 每件/每箱唯一 | BOX-260809-001 |
| 内部批次号 | b | B 必填 | 收货时生成的内部批次 | B260809-001 |
| 来源批号 | rb | 可选 | **供应商批次号或生产批号**（统一为"来源批号"），扫入留档 | SUP-BATCH-01 |
| 生产日期 | pd | 可选 | ISO yyyy-MM-dd | 2026-08-01 |
| 效期 | ex | 可选 | ISO yyyy-MM-dd | 2026-12-31 |
| 数量 | q | 可选 | 标签含数量时；decimal(18,4) | 50 |
| 单据类型 | ty | D 必填 | PO=采购 / PR=生产退料 / OT=其他（枚举后续与概念设计对齐） | PO |
| 单据号 | d | D 必填 | 预建单据编号 | PO-260809-001 |
| 仓库编码 | wh | D 可选 | 预建单据所属仓库 | WH-01 |

**明确不入码**：

- **供应商名称**：不入码（长、中文、增码长），由供应商编码/系统关联；打印可读文字时可显示。
- **物料名称**：不入码（已确认），系统按 s 查询；可读文字显示。

**约束矩阵**：

| t | 必填 | 说明 |
|---|---|---|
| S | v,t,s | 外标签：保证"这是什么物料"；可带 rb/pd/ex/q |
| U | v,t,s,u | 唯一码标签：扫码=物料+唯一个体 |
| B | v,t,s,b,q | 批次标签：扫码=物料+内部批次+数量 |
| D | v,t,ty,d | 单据二维码：扫码按"类型+单号"打开单据 |

## 五、内部生产入库的标签（新增说明）

内部生产入库（生产部门打印标签）**复用同一套规范**，不需要新标签类型：

- 收货前（生产完成、待入库）：打印 **t=S 外标签**，携带 `rb`（生产批号）、`pd`（生产日期），可选 `q`（生产数量，PDA 自动带出、操作员确认）。
- 收货后（批控物料）：系统生成内部批次号，按需打印 **t=B 批次标签**。
- 供应商名称不适用；"来源批号"字段同时覆盖"供应商批次号"与"生产批号"两种语义。

## 六、PDA 解析行为

| 扫到 | 行为 |
|---|---|
| AWMS1: t=S | 定位物料 → 数量输入/连扫累加；rb/pd/ex 扫入留档为批次属性 |
| AWMS1: t=U | 定位物料+唯一个体；在单据行唯一码清单内 → 勾销（重复扫=拦截）；不在清单 → 提示"不在本单" |
| AWMS1: t=B | 定位物料+内部批次 → 数量自动带出（质检/上架场景） |
| AWMS1: t=D | 按"单据类型 ty + 单据号 d"路由到单据服务，打开预建单据（本期统一表，见 ADR-003） |
| 外部条码 | 尽力解析 SKU/批次/日期（EAN/Code128/GS1 AI）→ 留档；解析不出 → 手动录入兜底 |

## 七、打印版式（已确认）

- 二维码（纠错 M）+ 下方**人类可读文字**：物料编码/名称/批次/数量/日期（扫码以外的可读性）。
- 批次标签可加"建议库位"文字（不入码，库位会变）。
