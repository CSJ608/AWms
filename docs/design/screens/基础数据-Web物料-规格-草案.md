# 界面规格：基础数据 Web 示例（物料管理页）（草案 v0.1，D-04）

> 状态：**草案（2026-08-09，讨论中）**。角色：系统管理员。示例页确定"主数据页"通用模式（列表+筛选+新建/编辑+导入导出），后续仓库/库位/批次沿用。
> 依据：调研笔记（导入导出两阶段）、框架设计（权限）。


## 二、字段与操作

| 项 | 说明 |
|---|---|
| 字段 | 编码（必填，唯一）、名称（必填）、批控（开关）、标签类型（无/SKU码/唯一码）、默认单位、状态（启用/停用） |
| 新建/编辑 | Dialog 表单（RHF+zod）；编码不可改（编辑时只读） |
| 删除 | AlertDialog 二次确认；被引用（单据/库存）→ 拦截 + toast（引用保护错误码） |
| 筛选 | 编码 + 名称（模糊），查询/重置；服务端分页 |
| 导入 | 下载模板 → 上传 → **预校验报告**（成功/失败明细：行号+列+原因）→ 确认执行 → 结果报告；本期仅"新增"，重复编码报错 |
| 导出 | 导出当前筛选结果（与模板同结构），留审计 |

## 三、导入导出交互（两阶段，平台能力）

1. 点[导入] → 弹窗：下载标准模板（含说明 Sheet）。
2. 上传文件 → 系统解析 → **只校验不落库**，显示报告：成功 N 行 / 失败 M 行（表格列出：行号、字段、原始值、错误原因、建议）。
3. 全部失败为 0 行时"执行导入"才可点（或允许部分成功——本期**建议全部成功才执行**，简单安全）。
4. 执行后显示结果报告；失败明细可导出。
5. 权限：导入/导出按钮按角色权限显示（管理员默认）。

## 四、状态矩阵

| 状态 | 表现 |
|---|---|
| 加载 | 表格骨架 |
| 空态 | "暂无物料，点击新建或导入第一批数据" |
| 错误 | 查询失败：错误条+重试；删除引用保护：toast 提示记录不消失 |
| 导入失败 | 预校验报告明细展示，不落库 |
| 无权限 | 新建/导入/导出按钮隐藏 |

## 五、交互细节

1. 筛选输入防抖（300ms）；筛选变化重置页码。
2. 新建成功 → toast + 刷新列表；编辑成功 → toast + 刷新。
3. 导入弹窗内完成全流程，不跳页；可关闭取消。
4. 标签类型字段：说明文案（无=手动输入、SKU码=非唯一连扫、唯一码=逐件防重）。

## 六、视觉锚点

- 表格高密度可扫读（等宽数字、状态徽章、操作列右对齐）。
- 主操作按钮：新建（主色）、导入/导出（次要）。

## 七、开放问题

1. 导入本期**仅新增**（重复报错），不做"更新已存在"——确认？
2. 导入执行策略：全部成功才执行（推荐），还是部分成功也执行？
3. 标签类型字段本期需要吗（物料主数据已含，但界面先暴露）？
