> 定稿决议：导入仅新增（重复报错）+ 全部校验通过才执行；物料页暴露"标签类型"字段。

## 二、字段与操作

| 项 | 说明 |
|---|---|
| 字段 | 编码（必填，唯一）、名称（必填）、批控（开关）、**标签类型（无/SKU码/唯一码）**、默认单位、状态（启用/停用） |
| 新建/编辑 | Dialog 表单（RHF+zod）；编码不可改（编辑时只读） |
| 删除 | AlertDialog 二次确认；被引用 → 拦截 + toast（引用保护错误码） |
| 筛选 | **SearchField[] 元数据驱动（评审 B-3）**：编码/名称（keyword）+ 标签类型 + 状态；固定参数 + filter DSL；查询/重置；服务端分页 |
| 导入 | 下载模板 → 上传 → **预校验报告** → 确认执行 → 结果报告；**仅新增**，重复编码报错；**全部校验通过才可执行** |
| 导出 | 导出当前筛选结果（与模板同结构），留审计 |

## 三、导入导出交互（两阶段，平台能力）

1. 点[导入] → 弹窗：下载标准模板（含说明 Sheet）。
2. 上传 → 系统解析 → **只校验不落库**：成功 N / 失败 M（行号、字段、原始值、原因、建议）。
3. 失败 0 行时"执行导入"才可点；执行后显示结果报告；失败明细可导出。
4. 权限：导入/导出按钮按角色权限显示。

## 四、状态矩阵

| 状态 | 表现 |
|---|---|
| 加载 | 表格骨架 |
| 空态 | "暂无物料，点击新建或导入第一批数据" |
| 错误 | 查询失败：错误条+重试；删除引用保护：toast 提示记录不消失 |
| 导入失败 | 预校验报告明细展示，不落库 |
| 无权限 | 新建/导入/导出按钮隐藏 |

## 五、交互细节

1. 筛选输入防抖（300ms）；筛选变化重置页码。
2. 新建/编辑成功 → toast + 刷新列表。
3. 导入弹窗内完成全流程，不跳页。
4. 标签类型字段带说明：无=手动输入、SKU码=非唯一连扫、唯一码=逐件防重。

## 六、视觉锚点

- 表格高密度可扫读（等宽数字、状态徽章、操作列右对齐）。
- 主操作：新建（主色）、导入/导出（次要）。
