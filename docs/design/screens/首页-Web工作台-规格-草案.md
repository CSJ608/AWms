> 状态：**已定稿 v1.1（2026-08-10 修订）**。角色：仓管/主管（主要）、作业员（浏览）。

## 二、区块与字段

| 区块 | 内容 | 数据来源（契约依赖） |
|---|---|---|
| KPI 卡（4 个） | 待质检 / 待上架 / 异常待办 / 可用SKU | 待检主体、暂存库位可用行、可用主体（现有契约可算）；异常数需聚合接口 |
| 待办列表 | 待质检单、待上架任务、异常 | 需聚合接口（契约批定义） |
| 快捷操作 | 新建入库单 / 打印中心 / 照片查看 | 页面跳转 |
| 最近库存流水 | 最新 10 条流水 | 现有契约 |

## 三、状态矩阵

| 状态 | 表现 |
|---|---|
| 加载 | KPI 骨架、列表骨架；不闪屏 |
| 空态 | KPI 为 0；待办显示"暂无待办，一切正常 ✓"；流水空态文案 |
| 错误 | 顶部错误条 + 重试；KPI 区单独失败不拖垮整页 |
| 无权限 | 对应入口/区块隐藏（注册表权限过滤） |

## 四、交互

1. 仓库选择器：多仓支持，记住上次；切换后数据重载。
2. 待办卡点击 → 直达对应页面。
3. 刷新：手动 + 进入页面自动；不轮询（原型）。
4. KPI 数字大号等宽数字，状态语义色。

## 五、视觉锚点

- 状态色：待检 amber / 可用 emerald / 冻结 sky / 异常 red。
- KPI 大而醒目；待办每行"是什么 + 多少 + 去哪"，可扫读。
- 中性简洁，无装饰渐变。
