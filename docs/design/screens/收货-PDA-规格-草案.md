# 界面规格：收货作业 PDA 原型（草案 v0.1，D-04）

> 状态：**草案（2026-08-09，讨论中）**。角色：收货/质检/上架员。目标：**扫码为主、一屏一任务、自动跳下一步、错误当场拦**。
> 依据：收货链工作流 v0.3.2、标签规范 v0.4、调研笔记（PDA 设计原则）。

## 一、屏幕流

```text
主界面（我的作业）
  → ① 定位收货上下文（新建 / 扫单据二维码）
  → ② 选入库类型（仅新建时：采购/生产/其他）
  → ③ 行录入（扫码区 + 当前行卡片 + 大数字键盘）
  → ④ 确认提交（行汇总 + 差异提示 + 拍照可选）
  → ⑤ 结果页（成功 + 打印回执 + 继续下一单）
```

## 三、扫描与输入规范（核心）

| 扫到 | 反馈 | 行为 |
|---|---|---|
| AWMS1 外标签 S | 绿 + 短音 | 定位物料；数量输入/连扫累加（非唯一） |
| AWMS1 唯一码 U | 绿 + 短音 | 勾销；重复扫 → 红 + 长音 + "已收过" |
| AWMS1 批次标签 B | 绿 + 短音 | 带出物料+内部批次；生产退料复用批次 |
| AWMS1 单据码 D | 绿 + 短音 | 打开预建单据（按 ty+d 路由） |
| 外部条码 | 黄 + 提示 | 尽力解析；失败 → 手动录入兜底 |
| 校验失败 | 红 + 长音 | 当场提示修正，不产生脏数据 |

- 扫码框常驻聚焦；扫到即处理，不需要点"确定"。
- 数量输入：大数字键盘 + 步进按钮（±1/±10）；非唯一码连扫自动 +1。
- 已知信息预填：上次仓库、当前单据上下文。

## 四、状态矩阵

| 状态 | 表现 |
|---|---|
| 加载 | 顶部进度条；不阻塞扫码 |
| 空态 | 待办为空显示"无待办"；扫描无匹配显示"未识别" |
| 错误 | 红底提示条 + 长音；可重试 |
| 无权限 | 入口隐藏（注册表过滤） |
| 网络失败 | 提示"请检查网络"并保留当前输入（本期不做离线） |

## 五、交互细节

1. 一屏一任务：成功后自动进入下一步/下一单。
2. 大触控目标（≥48px）、宽间距、单手拇指区；高对比大字。
3. 声音反馈可调音量；成功/失败音色区分（嘈杂环境）。
4. 严格策略：数量≠单据 → 拦截，提示"数量与入库单不一致，需作废重建或联系主管"。
5. 宽松策略：差异提示并记录，不阻断。
6. 拍照：可选 1-3 张；在确认页操作，不打断主线。
7. 打印：结果页"打印收货回执"；Web 可补打。

## 六、视觉锚点

- PDA 基线：深色高对比（或浅色高对比）、超大字体、大按钮、声音反馈。
- 状态语义色贯穿：待检 amber / 可用 emerald / 异常 red。
- 顶部始终显示当前上下文（单号/仓库），底部主操作按钮固定。
