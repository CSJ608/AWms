# 界面规格：通用列表页 + 通用 Dialog 表单（草案 v0.1，评审 B-4/B-5）

> 状态：**草案 v0.1（2026-08-10，评审采纳）**。模板化规格，以下页面声明复用：入库单列表、打印中心、照片查看、用户管理、角色管理、批次浏览。
> 依据：通用规范 v1.8（filter DSL/sort/字段元数据/ref）、框架设计 v0.2（注册表）。

## 一、通用列表页
```
┌──────────────────────────────────────────────────────┐
│ 标题            共 N 条 · 当前筛选 M 条                 │
│ [ + 新建 ] [ 导入 ] [ 导出 ] [ 打印 ]（按权限显隐）        │
│ 筛选区：SearchField[] 元数据驱动（字段/控件/操作符）       │
│  [查询] [重置] [高级筛选展开/收起]                       │
├──────────────────────────────────────────────────────┤
│ DataTable（列定义 → 列；行操作：查看/编辑/删除/打印/作废）   │
│ 空态/加载骨架/错误条/无权限态                           │
│ 分页：第 1 / 7 页 · 每页 20 条   [上一页] [下一页]         │
└──────────────────────────────────────────────────────┘
```

## 二、通用 Dialog 表单
```
┌──────────── Dialog ────────────┐
│ 标题（新建/编辑）                │
│ 字段：由表单 schema 驱动         │
│  ref 字段 → ReferencePicker     │
│  enum 字段 → 下拉（options）     │
│  decimal → 数字输入（字符串）     │
│  [取消] [保存]（校验失败 inline） │
└────────────────────────────────┘
```

## 三、复用声明（评审 B-5）
| 页面 | 列表资源 | 新建/编辑 | 特殊操作 |
|---|---|---|---|
| 入库单 | GET /api/inbound-orders | Dialog（type/lines 行编辑器） | 作废（AlertDialog+原因） |
| 打印中心 | GET /api/print/jobs（打印记录） | — | 打印任务重打/下载 PDF |
| 照片查看 | GET /api/attachments?bizType=&bizId= | 上传（multipart） | 缩略图网格 + 原图查看 |
| 用户管理 | GET /api/users | Dialog | 重置密码、分配角色 |
| 角色管理 | GET /api/roles | Dialog | 分配权限点 |
| 批次浏览 | GET /api/batches（keyword 分页） | 只读 | 按物料筛选（ref） |

## 四、交互细节
1. 筛选区：常用字段默认展开（2-3 个），其余“高级筛选”收起；SearchField[] 来自运行时元数据端点（GET /api/meta/fields/{resource}）。
2. 列表列宽/排序可配置（列定义驱动）；操作列右对齐。
3. 表单校验失败 inline 提示（zod）；提交失败 toast（后端 message）。
4. 删除/作废：AlertDialog 二次确认；引用保护 → toast（message）+ 记录不消失。
