# 界面规格：质检 / 上架 PDA（草案 v0.1，评审 B-4）

> 状态：**草案 v0.1（2026-08-10，评审采纳）**。沿用收货 PDA 基线（一屏一任务、扫码优先、大触控、声音反馈）。

## 一、质检流程
```
质检待办列表                    质检确认屏
┌────────────────┐   ┌────────────────┐
│ ← 质检   WH-01   │   │ ← 质检          │
│ RCP-... MAT-001  │   │ MAT-001 螺母 M6  │
│ 批次 260810001   │   │ 批次 260810001   │
│ 200 件  08-10    │   │ 应检 200         │
│ [扫码/选择]      │   │ [PASS 通过]      │
│ 待办：2 单       │   │ [异常：拍照+原因] │
└────────────────┘   └────────────────┘
异常上报屏
┌────────────────┐
│ 异常上报         │
│ 原因：[破损 ▾]   │
│ [拍照 0/3]       │
│ 备注：[______]   │
│ [提交异常]       │
└────────────────┘
```

## 二、质检交互
1. 待办列表：扫码（批次标签 t=B 直接定位行）或点击选择；显示单据号/物料/批次/数量。
2. 确认屏：PASS=一键通过（状态→可用）；异常=拍照（0-3 张）+ 原因（枚举：破损/数量不符/其他）+ 备注 → 提交（EXCEPTION，待主管 resolve）。
3. 主管 resolve 在 Web（通用列表/详情 + 操作），PDA 不处理。

## 三、上架流程
```
上架待办 -> 推荐库位屏 -> 拆分确认屏 -> 扫码确认屏 -> 结果
┌────────────────┐   ┌────────────────┐   ┌────────────────┐
│ ← 上架          │   │ 推荐库位         │   │ 确认上架        │
│ MAT-001 200 件   │   │ DFT-01（理由：   │   │ 库位 DFT-01     │
│ 批次 260810001   │   │  同物料集中）    │   │ 批次 260810001  │
│ 暂存 STG-01      │   │ [改用此库位]     │   │ 数量 200        │
│ [开始]          │   │ [其他库位]       │   │ [扫库位码确认]   │
└────────────────┘   └────────────────┘   └────────────────┘
拆分确认屏（打印批次标签）
┌────────────────┐
│ 每标签数量 [10]   │
│ 将生成 20 张      │
│ （尾数：最后 1 张 0）│
│ [打印并贴标]     │  <- 降级：预览+二维码（P-01）
└────────────────┘
```

## 四、上架交互
1. 待办：行级（receiptLine.status=CHECKED 且未上架）；显示暂存库位。
2. 推荐库位：展示推荐 + 理由；可改选（ReferencePicker 轻量按 type=DEFAULT 过滤）。
3. 拆分打印：每标签数量默认 defaultQtyPerLabel（可改）；N=ceil；尾数最后一张；打印降级见 P-01。
4. 确认：扫目标库位码（必须）→ 提交（物理库存 staging→目标 + 流水）。
