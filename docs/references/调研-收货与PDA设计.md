# 调研笔记：收货流程与 PDA 作业设计（2026-08-09）

> 参考输入，不参与标准。来源为公开资料，用于讨论时的借鉴。

## 1. 扫码作业的本质

- 用"扫码校验"替代"人眼核对"：每个 SKU、库位、单据都编码，系统每次扫码自动比对——对，放行；错，报警。
- **条码覆盖率是前提**：商品码 + 库位码必须全覆盖，否则流程反复被打断、退回手工录入。
- 库位编码建议层级结构（区域-巷道-货架-层），让人看码即知位置。
- 来源：万里牛《WMS条码作业全流程》https://www.hupun.com/articles/wms-barcode-operations-inbound-outbound-cycle-count-scan-process.html

## 2. 收货流程要点（行业共识）

- 到货预报/ASN 先行：扫描到货箱码/物流单号 → 系统调出应到 SKU、数量、效期 → 差异当场发现处理，而不是入库后才发现。
- **质检单独设节点**，不与收货合并；区分免检/抽检/全检规则；未完成质检确认的货锁定上架权限。
- 上架：系统推荐库位（附理由）→ 操作员扫码库位 + 扫码商品 → 确认入账。
- 来源：搜狐《出入库流程梳理》https://m.sohu.com/a/1047586909_391599 、科箭、万里牛

## 3. 收货理货上架"一体化"的教训（重要）

- **电子化 ≠ 一体化**：只把线下单据变成线上任务推送，人会照样绕路、重复录入。
- 常见浪费：信息滞后（理货员先找收货员要信息）、环节间重复录入（同一批货录 3 次）、异常处理无预设路径（一次异常平均 17 分钟）。
- 好设计：
  - 系统给**"建议清单 + 理由"**，不是死命令（推荐库位附理由，采纳率显著上升）；
  - 异常处理内置在流程里，**三级漏斗**：一级自动可解（自动换库位）→ 二级远程复核（主管远程介入）→ 三级现场全权（先处理后补单，系统事后触发盘点）；
  - **环节预热**：上一环节未结束时，系统提前准备下一环节信息（预分配库位清单）；
  - 小差异容差（如 ±5%）允许先按实际收货，差异自动发起报告，不整批锁定等主管。
- 来源：九数云《收货理货上架一体化作业》https://www.eshutong.com/archives/35954.html

## 4. PDA 作业界面设计原则

- **一屏一任务**：每屏只聚焦当前任务所需的最少信息；线性引导，自动跳下一步。
- **扫描是主要输入**：预填已知信息，减少手动输入；扫描成功/失败有明显声音 + 颜色反馈（嘈杂环境声音更重要）。
- **大触控目标、宽间距**：戴手套/快速操作也能点准；核心按钮放在拇指易达区域；单手操作。
- **异常上报一键化**：一键上报 + 简短描述/拍照，流程内置，不打断主线。
- **离线能力**：仓库信号盲区刚需——核心扫描/简单任务记录离线，恢复网络后自动同步。
- 来源：猪八戒《仓储App用户体验设计策略》https://nmg.zx.zbj.com/baike/39524.html 、Scandit《Scanning at Scale》https://www.scandit.com/blog/scanning-at-scale-ux-insights/

## 5. 导入导出：做平台级能力，不要每个模块各写一套

- 统一框架：模块定义 + 字段元数据 + 方案 + 模板 + 任务。
- 三种导入模式：标准模板 / 智能列头映射（别名）/ 手动映射。
- **两阶段导入**：先预校验（不落库），再正式导入；失败明细精确到行/列/原因/建议。
- 校验分层：文件级 → 字段级 → 引用级 → 行级业务 → 跨行。
- 权限与审计：模块权限、字段权限（如成本价可看不可导出）、导入导出留痕。
- 模板建议：数据 Sheet + 说明 Sheet + 字典 Sheet；列头可用两行（显示名 + 系统编码）。
- 来源：升鲜宝《通用导入导出设计》https://www.cnblogs.com/sunplay/p/19875979 、ShipOut、SmartWMS

## 6. 拍照追溯

- 收货/装车时拍照记录货物状况，作为争议/审计证据；未来可导出查看。
- 相关系统已支持：收货拍照、卡车装载拍照、承运人签名采集；D365 建议在收货/盘点/异常处理中内置图片采集步骤。
- 来源：Mecalux https://www.mecalux.com/software/updates/photo-capture 、Dynamics 365 Ideas

## 7. 单据打印

- 模板化：按业务类型（收货单、拣货单、发货单、库位标签）独立配置模板；模板可快速自动匹配。
- 打印与任务联动：单据生成后自动打印/批量打印；标签打印用于条码化基础建设。
- 来源：C-WMS《打印模板这样配》https://www.c-wms.com/new/end_3377.html 、腾讯云《打印服务开发》

## 8. 权限框架

- 分层：路由权限（模块）、菜单权限（可见性）、功能/按钮权限（操作）；查看与操作分开。
- 模块注册表驱动菜单，新增模块不需改框架。
- 来源：掘金《wms系统用户管理功能总结》https://juejin.cn/post/6948994560777256973 、ShipOut 权限升级

## 9. AGV 仓预留（本期只留概念位）

- WMS 与 AGV 调度系统（RCS/ECS）集成要点：任务下发 → 状态回告 → 异常重新指派；库位推荐考虑 AGV 可达性、热度分区、AGV 密度。
- **本期只需预留**：库位可达性属性（AGV 可达/仅人工）、任务执行主体（人/AGV/外部系统）、任务状态回告接口位。
- 来源：成都蓉西《AGV与WMS深度集成》https://www.cdrongxi.com/news-18/876.html 、九数云《任务闭环》https://www.eshutong.com/archives/34986.html
