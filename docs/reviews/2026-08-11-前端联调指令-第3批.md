## 三、联调冒烟清单（以 docs/api/ 契约为准）

- [ ] **登录/会话**：登录成功进入后台；过期 token 走 401 单飞刷新换新、会话不踢；登出 204 回登录页。
- [ ] **用户/角色/权限**：GET /api/users（keyword/status/分页）；新建用户重复用户名 409；角色分配权限；GET /api/permissions 只读。
- [ ] **主数据 CRUD**：物料新建（重复码 409）/编辑（code 只读）/删除（被批次引用 409）；仓库/库位（仓内重复 409）/来源。
- [ ] **列表查询（契约 v1.9）**：标准列表 `POST /{resource}/search`（body：keyword/固定参数/filter/sort/page/pageSize），filter DSL 生效、白名单外 400；引用选择器快捷搜索 `GET /{resource}?keyword=&pageSize=`。
- [ ] **批次**：`POST /api/batches/search` 默认 createdAt DESC（最新在前）；`GET /api/batches?keyword=`；嵌套 `POST /api/materials/{id}/batches/search`（物料不存在 404）。
- [ ] **导入**：模板下载 → precheck（失败明细 inline ≤200，重复码 MATERIAL_CODE_DUPLICATED）→ 全部通过才可 execute → **执行后库中可查**。
- [ ] **导出**：创建任务返回 PROCESSING → 轮询 DONE → 下载文件；导出内容符合 filter/sort/pageSize（与库核对条数与顺序）。
- [ ] **幂等**：同一写请求重复带相同 Idempotency-Key 只入库一次、返回首次结果。
- [ ] **权限**：无操作权限账号（如 OPERATOR）访问写端点 → 403 FORBIDDEN，前端按 code 提示。
