## 1. 完成范围

- B-01 入库链与库存写侧模型：新增入库单/行、唯一码、收货/行、质检、上架、库存主体、库位库存、事务组、流水、附件、PrintJob/PrintJobItem；迁移包含锁定契约要求的关键唯一约束与索引。
- B-02 入库单：实现创建、列表查询、详情、作废；落实 PO/PR/OT 来源规则、编号服务、行号后端分配、PO 严格策略和幂等写端点。
- B-03 标签解析与收货：实现 `POST /api/scan/parse` 与 `POST /api/receipts`；支持有单/无单 PR/OT、批次创建/复用、唯一码数量守恒、暂存库位校验、待检库存与收货流水同事务。
- B-04 附件：实现上传、查看、缩略图、列表、删除保护；业务提交内按“未关联 + 上传人匹配”并发认领。
- B-05 质检：实现质检待办、PASS、EXCEPTION、主管 PASS/REJECT；PASS/主管 PASS 同事务执行待检到可用库存转换和流水。
- B-06 上架：实现上架待办、推荐库位、目标库位校验、`expectedInventoryVersion` 乐观并发、暂存到目标库位库存转移与流水。
- B-07 打印：实现单据码、外标签、唯一码、批次标签、PDA 单张批次标签、收货回执、作业查询/详情/retry/file；唯一码登记、PrintJob、PrintJobItem 同事务。
- B-08 权限与测试：新增第 4 批 8 个 action 权限和 PDA 菜单；新增单元测试与 PostgreSQL Testcontainers 集成测试，覆盖状态机、幂等、并发、附件认领、库存守恒和失败无部分写入。
- `e417ab9..c81a069` 完工审核整改：禁止同请求重复 PO 行；使用 PostgreSQL 条件更新保护共享 PhysicalInventory 并保持流水余额链守恒；强制关键写接口 Idempotency-Key 并将业务结果与幂等完成记录纳入同一事务；修复 resolve 竞态；补齐打印状态机、可靠 PDF/二维码、附件权限/真实缩略图、EAN/Code128/GS1 解析和 Receipt filter/sort；增加关键并发、幂等、安全与打印失败恢复测试。
- `c81a069..cb04225` 过程复审整改：移除 `IdempotencyFilter` 和 `AttachmentService` 中永久增长的静态 keyed-lock 字典。幂等并发统一使用 PostgreSQL 事务级 advisory lock；缩略图改为独立临时文件完整生成后原子竞争落盘，不使用可能造成同 key 并发失锁的简单 `TryRemove`。
