## 二、契约与规格决议

| 议题 | 决议 | 回写位置 |
|---|---|---|
| 预建单收货的批次属性 | 有单与无单收货行均支持 `batchId? / batchProps?`，二者互斥；PR 生产退料才允许复用 batchId | `api/收货.md`、PDA 收货规格 |
| 唯一码数量守恒 | `UniqueCode` 保存 quantity；扫码结果返回 quantity；提交行 quantity 必须等于唯一码 quantity 之和 | `api/标签解析.md`、`api/收货.md`、`api/数据模型-草案.md` |
| 单据码扫码上下文 | `t=D` 一次返回 inboundOrderId、仓库、状态和完整行列表；PDA 不再按 docNo 二次搜索 | `api/标签解析.md`、PDA 收货规格 |
| 打印作业闭环 | 使用 `PrintJob + PrintJobItem` 持久化作业、项目、文件状态和失败码；不再保留语义重叠的 PrintLog | `api/打印.md`、`api/数据模型-草案.md` |
| 数据库并发防重 | 补入库行、收货行、唯一码、质检、上架、流水和打印项唯一约束、索引及并发集成测试标准 | `api/数据模型-草案.md` |
| 附件归属 | 收货照片=`RECEIPT/receiptId`；异常照片=`EXCEPTION/qualityCheckId`；PASS 无照片，QUALITY_CHECK 本批预留 | `api/附件.md`、`api/收货.md`、`api/数据模型-草案.md` |
| 上架标签默认值 | `PutawayTodo` 直接返回 `defaultQtyPerLabel`；为空时整行 1 张 | `api/收货.md`、质检上架 PDA 规格 |
| DTO 可空性 | 入库单、收货单和收货行按预建/无单场景明确 required、nullable 和条件字段 | `api/入库单.md`、`api/收货.md` |
| Web 标签打印交互 | 在单据行操作中打开参数对话框；不做多行勾选。外标签填 count；唯一码填 count/qtyPerCode 并展示登记总量 | Web 入库管理规格、`api/打印.md` |

## 三、用户裁决

1. 来源主数据：PO 必须选择启用的 `SUPPLIER`；PR 必须选择启用的 `WORKSHOP`；OT 来源可空，填写时必须引用启用的 Source。
2. Web 打印：单据行级操作 + 参数对话框，本批不做多行批量打印。
3. 批次标签定位待办：恰好 1 条自动打开；多条展示候选列表；0 条提示无匹配，不得静默选择第一条。
