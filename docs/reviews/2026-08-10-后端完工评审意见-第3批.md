### R-04（B-02）LoginResponse 形状与契约/前端不一致 —— 登录成功后前端无法进入后台

- 前端 `types.ts` 严格按契约定义 `menus.web / menus.pda / user`，登录后读 `menus.web` 为 undefined → 菜单渲染/会话恢复失败。
- 修复要求：LoginResponse 按契约 v0.2 结构输出（user 含 roles、menus.web/pda、permissions、expiresAt），并同步修正菜单种子/装配逻辑。

### R-05（B-06）导入 execute 是空实现，且 CanExecute 永远不会为 true
- 契约 v0.2：precheck **不落库** → 全部通过（canExecute=true）→ execute **在同一事务内重新校验唯一性** 并真实入库。
- 实际（`ImportExportService.cs`）：
  1. `PrecheckAsync` 把校验结果明细写入 `ImportTaskDetail`（依赖 DB 落库结果），且**从未把 `task.CanExecute` 置 true**（全文件仅第 183 行读取、第 285 行映射，无任何赋值）。

- 影响：导入功能完全不可用；"物料导入导出"是本批可演示工作流的核心能力，此缺陷直接击穿批目标。
- 修复要求：precheck 不落业务数据（校验明细可留痕但须明确契约边界）；execute 读取文件重新解析 → 事务内重校验唯一性 → 真实创建物料 → 提交；重复码返回契约错误码；补导入 E2E 测试（precheck→execute→库中数据核对）。

### R-06（B-03）编号服务非原子自增 —— 无行锁、无并发测试、无耗尽测试
