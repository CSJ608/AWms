# ADR-002：PDA 优先的作业终端 + 人工仓为主、预留 AGV

> 状态：已采纳（2026-08-09）

## 背景

用户目标：**一线操作人员只用 PDA 就完成全部操作，尽可能减少手动输入**；考虑 PDA，不考虑扫码枪。
仓库类型：支持人工管理仓与 AGV 管理仓；AGV 任务派发最后考虑，本期以人工仓为主，但要预留适配能力。

## 决策

1. **作业终端以 PDA 为主**：收货/质检/上架等一线操作全部在 PDA 完成；扫码是主要输入方式，减少手动输入。
2. **Web 后台负责**：主数据维护（含导入导出）、库存查询、单据打印、拍照查看、异常处理、系统管理。
3. **不接扫码枪**（本期及近期）；PDA 的扫描能力由设备本身提供。
4. **预留 AGV 适配的概念位**（本期不实现，只留设计）：
   - 仓库/区域可标记管理方式（人工 / AGV）；
   - 库位带"可达性"属性（如 AGV 可达 / 仅人工可达 / 地堆限制），出库拣货时按执行主体过滤；
   - 作业任务带"执行主体"概念（人 / AGV / 外部系统），为任务派发与状态回告留接口位。

## 影响

- 概念设计需包含：PDA 作业概念、库位可达性、任务执行主体（预留）。
- 界面规格分为两条线：PDA 作业线（收货/质检/上架/盘点）与 Web 管理线（主数据/查询/打印/拍照查看/系统）。
- 契约需考虑附件（拍照）、打印、导入导出的通用能力。

## 备选方案

- 扫码枪 + PC 作业：**否决**，用户明确要 PDA。
- 一期就做 AGV：**否决**，用户明确最后考虑，本期人工仓为主。
