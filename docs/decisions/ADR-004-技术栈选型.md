# ADR-004：技术栈选型（v0.2，部分已采纳）

> 状态：**v0.2（2026-08-10）**。后端/PDA/附件/打印已确认；**前端选型待前端 AI 评审意见**（评审输入见 docs/iterations/active/前端评审输入-第2批.md）。

## 背景

第 2 批（契约批）需要先锁定技术栈。本机环境：.NET SDK 9.0 / 10.0（10 为 LTS）、Node 26、pnpm 11。

## 已确认（2026-08-10 用户确认）

| 层 | 选型 | 状态 |
|---|---|---|
| 后端 | **.NET 10（LTS）+ ASP.NET Core Web API + EF Core + PostgreSQL** | ✅ 已确认 |
| PDA | **同一前端代码库的移动端 Web（PWA）**；扫码枪=键盘输入；离线后置 | ✅ 已确认 |
| 附件（拍照） | 本地文件存储 + 数据库元数据（云存储后置） | ✅ 已确认 |
| 打印 | 本期浏览器打印（PDF）+ 内置模板；PDA 打印后置 | ✅ 已确认 |

## 待评审（前端）

| 层 | 建议基线 | 状态 |
|---|---|---|
| 前端 Web | React 19 + Vite + TypeScript strict + Tailwind v4 + shadcn/ui | 🟡 待前端 AI 评审（可提替代） |
| 数据请求/状态 | TanStack Query（建议） | 🟡 随前端评审 |
| 表单/表格 | RHF + zod / TanStack Table（建议） | 🟡 随前端评审 |
| i18n/主题 | i18next / next-themes（建议） | 🟡 随前端评审 |
| 测试/构建 | Vitest + RTL / Vite（建议） | 🟡 随前端评审 |

## 备选

- PDA 原生 App / 独立 PDA 项目：成本高、双份维护 → 否决（本期）。
- 后端 Java/Spring：团队无既有资产 → 否决。
- 打印接 TemplateFrame 全套：等打印需求明确（第 5 批前）再评估。
