# ADR-004：技术栈选型（v0.3，已采纳）

> 状态：**已采纳 v0.3（2026-08-10，用户确认 + 双向评审采纳）**。

## 背景
第 2 批（契约批）锁定技术栈。本机：.NET SDK 9/10（10 为 LTS）、Node 26、pnpm 11。

## 决策（已确认）
| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | .NET 10（LTS）+ ASP.NET Core Web API + EF Core + PostgreSQL | 迁移版本化；禁止 AI 对已有表 DROP/ALTER COLUMN（仅 ADD nullable + 新表） |
| 前端 | React 19 + Vite + TS strict + Tailwind v4 + shadcn/ui + TanStack Query + RHF/zod + TanStack Table + i18next + Vitest + RTL | 双路由树（web/pda）+ 共享组件层 |
| mock 层 | **MSW**（browser+node），VITE_USE_MOCK 开关；pnpm 已验证可装（2026-08-10，msw 2.15.0） | 契约 DTO→TS 类型唯一事实来源 |
| PDA | 同一前端代码库移动端 Web（PWA）；扫描头=键盘输入；ScanInput 抽象（专用 PDA 为主 + 摄像头 BarcodeDetector/zxing 兜底，P-20） | 双路由树；PWA 预留（不缓存 API） |
| 附件 | 本地文件存储 + 元数据表；根路径 Storage:AttachmentsRoot；bizType/yyyy/MM 分桶；{uuid}.{ext} | 物理删除异步（评审 A-2） |
| 打印 | 浏览器 PDF（**QuestPDF**，评审 A-3）；PDA 单张=接口本期做 + spike（P-01）+ 界面降级预览 | 模板内置；配置界面后置 |
| 导入导出 | 后端平台能力（两阶段+失败明细），参考 TemplateFrame 思路自研 | — |

## 前端实现约束（评审采纳）
MSW mock 层；双路由树；ScanInput；401 单飞刷新+排队重放（以 401 响应触发）；decimal.js + dayjs；Idempotency-Key 按用户动作粒度注入；PWA 预留；路由静态注册+权限过滤；src/platform 目录。

## 备选
PDA 原生 App（否决）；Java 后端（否决）；PuppeteerSharp/iText（不选，QuestPDF 足够）。
