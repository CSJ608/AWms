## 三、合并前待办

### 1. NU1903（P2，必须收尾）Microsoft.OpenApi 2.0.0 已知漏洞
- 事实：Microsoft.AspNetCore.OpenApi 10.0.4 传递依赖 Microsoft.OpenApi **2.0.0**；GHSA-v5pm-xwqc-g5wc 受影响区间 `>=2.0.0-preview.11, <=2.7.4`，**首个修复版本 2.7.5**（最新 2.11.0）。
- 影响：项目 `TreatWarningsAsErrors=true` + 默认 NuGet 审计 → **全新 restore 时 `dotnet build` 直接失败（NU1903）**；当前“0 error 0 warning”需带 `-p:NuGetAudit=false`（汇报已如实注明）。
- 建议：`Directory.Packages.props` 加 `<PackageVersion Include="Microsoft.OpenApi" Version="2.11.0" />`，`AWms.Api.csproj` 加直接 `<PackageReference Include="Microsoft.OpenApi" />`（一行级改动），使默认构建（含审计）0 error 0 warning。
- 处理方式：**建议后端补一个 commit**（按分工后端管代码）；或经用户授权由协调者在合并时一并处理。
