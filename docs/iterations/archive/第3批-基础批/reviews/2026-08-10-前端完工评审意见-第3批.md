## 一、需修复（阻塞 F-06 验收依据）

### F-R1 测试在 Node v26 下不可复现：i18n 模块顶层裸用 `localStorage`
- 现象（协调环境 Node v26.7.0）：
  - `pnpm test` 直接运行：9 个测试文件全部失败、0 用例执行，报 `TypeError: Cannot read properties of undefined (reading 'getItem')`，栈在 `src/i18n/index.ts:15`（`detectLanguage` 顶层执行 `localStorage.getItem`）。
  - 原因：Node 26 自带实验性全局 `localStorage`（未加 `--localstorage-file` 时为 undefined），遮蔽了 jsdom 注入的全局 localStorage；`i18n/index.ts`、`session-store.ts` 均直接裸访问 `localStorage`。
  - 加 `NODE_OPTIONS=--localstorage-file=...` 后：54 个用例可执行，但结果为 43 过 / 11 败，且再次运行结果漂移（31 过/33 用例），存在套件崩溃，不能视为绿。
- 要求：
  1. localStorage 访问改为环境兼容写法（如 `window.localStorage` + `typeof localStorage === 'undefined'` 守卫，测试 setup 中统一 stub）；
  2. 固定 Node 版本（package.json `engines`/`packageManager`，或 .nvmrc，并在汇报中写明验证用 Node 版本），保证"测试绿"可复现；
  3. 修复后在当前环境复验 `pnpm test` 全绿。
