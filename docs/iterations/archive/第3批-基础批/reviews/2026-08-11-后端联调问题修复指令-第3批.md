## 三、修复任务（每项一个 commit，任务内可小步多次提交）

### F-01（Q1，P1，必须）错误响应 envelope 统一 camelCase
- **目标**：所有错误响应 JSON 顶层键统一小写 `code/message/data`（契约 2.1），消除 PascalCase。
- **做法**：
  1. `ExceptionHandlerMiddleware` 序列化改为 `JsonSerializerOptions { PropertyNamingPolicy = JsonNamingPolicy.CamelCase, Encoder = JavaScriptEncoder.UnsafeRelaxedJsonEscaping }`（与 `IdempotencyFilter` 一致）；
  2. 全仓排查其他 `WriteAsync(JsonSerializer.Serialize(...))` 手写序列化点，统一走同一 options；
  3. 补契约测试：断言 401（登录失败）、409（重复码）、422（导入拒绝）、403（权限）、404 的响应 JSON 顶层含 `code` 且**不含** `Code`。
- **自检**：`dotnet build` 0 error 0 warning；`dotnet test` 相关用例绿。

### F-02（Q6，P1，必须）JWT 密钥单一来源
- **目标**：只注入 `AWMS_JWT_SECRET` 即可正常登录（无需再注入 `Jwt__SecretKey`）。
- **做法**：
  1. Program.cs 在配置 JwtBearer 与 `AddInfrastructure`（JwtOptions 绑定）前，把解析出的密钥回填到配置：`configuration["Jwt:SecretKey"] = secretKey;`（secretKey 仍优先读 `Jwt:SecretKey`，否则读 `AWMS_JWT_SECRET`，缺失抛错逻辑保留）；
  2. 补测试：集成测试用独立 WebApplicationFactory，**只注入 `AWMS_JWT_SECRET`**（不设 `Jwt:SecretKey`），断言 `POST /api/auth/login` 200 且可访问受保护端点；同时保留“未配置密钥启动即抛错”的用例。
- **自检**：仅 `AWMS_JWT_SECRET` 环境下登录 200；原 500 IDX10703 不再出现。

### F-03（Q2 已裁决 + Q3 已裁决，P2）读端点路由权限 + 仓库/库位/来源操作权限码
- **目标**：读端点按资源挂 `route.<moduleCode>`；补 `action.warehouse/location/source.*` 权限码并修正写端点误用。
- **做法**：
  1. **Q2 读端点权限**：`[RequirePermission("route.master-data")]` 加到 Materials/Warehouses/Sources/Batches/ImportExport/Meta 控制器类级；`[RequirePermission("route.system")]` 加到 Users/Roles/Permissions 控制器类级（Auth 控制器除外；RequirePermission 的 AllowAnonymous 豁免保留）。类级+方法级同时存在时，先过类级 route、再过方法级 action（无 route 权限先 403）。
  2. **Q3 权限码**：注册表补 9 个码（固定 GUID，延续 3000… 段）：`action.warehouse.create/edit/delete`、`action.location.create/edit/delete`、`action.source.create/edit/delete`（moduleCode=master-data）；种子：SYSTEM_ADMIN 全量、SUPERVISOR 增加这 9 个码；OPERATOR 保持 inbound 不变。
  3. 控制器改码：WarehousesController（含库位）写端点改用 `action.warehouse.*` / `action.location.*`；SourcesController 改用 `action.source.*`；MaterialsController 保持 `action.material.*`。
  4. **迁移**：种子变更用 `dotnet ef migrations add AddMasterDataActionPermissions` 生成新迁移（禁 EnsureCreated），SQL 随代码提交供 review。
  5. 测试：SUPERVISOR 写仓库/来源 200；OPERATOR 写仓库/来源 403；OPERATOR `GET /api/users`、`POST /api/materials/search` → 403；admin 读/写全部 200；`GET /api/permissions` 含新 9 码。
- **自检**：`dotnet test` 全绿；`dotnet build` 0 error 0 warning。

### F-04（Q4，P3，应补）GET /api/meta/fields/users
