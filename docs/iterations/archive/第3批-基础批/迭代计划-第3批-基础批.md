## 目标

## 回顾（2026-08-11 批末填写）
- 本批经历三轮：初次完工（不通过）→ 任务化重做（复验通过）→ 联调修复（抽查发现 Q1/Q6 等并闭环）。核心教训：**任务化提交 + 真实测试不 Skip + 汇报如实** 是质量门槛；联调是发现契约/实现偏差的关键手段。
- 沉淀：错误 envelope 统一 camelCase（ApiJsonOptions）；JWT 密钥单一来源；读端点路由权限与操作权限分级；searchCode 不要求唯一（契约澄清）；Microsoft.OpenApi ≥2.7.5（NU1903）。
- 遗留/后置：异步导出 HostedService、幂等严格同事务、库位“有货”保护（第 5 批库存表）、批次/收货建批次（第 4 批）、页面级菜单粒度（Q7 建议）。
