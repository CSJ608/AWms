## 需要确认的疑问

### Q1（最重要）— 测试账号：A4 停用账号、C4 OPERATOR 账号测试库里都没有

- **背景**：已核对后端种子（AWmsDbContext.SeedData）：只种了 admin 用户（`Admin__ResetOnStartup=true`，api 每次启动重置）；OPERATOR/SUPERVISOR 角色存在但**无对应用户**，也无停用账号。
- **建议**：用 admin 在用户管理里新建 OPERATOR 用户（C1 本来就要测"新建用户+分配角色"），随后用于 C4；停用账号经 C1 创建后通过用户编辑制造（若无停用开关则 psql 改 status），并在报告中注明手段。
- **请确认**："测试中通过 UI/psql 造测试数据（不动代码）"是否认可？测试产生的脏数据（物料/仓库/用户等）验收后由我清理，还是保留供协调者复验？

### Q2 — A7"过期 token 单飞刷新"怎么造过期

- **背景**：AccessToken 有效期 `02:00:00`（appsettings.json），等待不现实。
- **建议**：从 `deploy/.env` 取 AWMS_JWT_SECRET，本地用同一密钥**签发一个已过期的 access token**，注入浏览器存储后访问受保护页面，观察 401 → 单飞刷新 → 自动重放。全程不动代码、不改 DB。
- **请确认**：此方案是否可行？或协调者另有推荐手段（如 psql 把 refresh token 过期时间改为过去，测"刷新失败→回登录"分支）。
