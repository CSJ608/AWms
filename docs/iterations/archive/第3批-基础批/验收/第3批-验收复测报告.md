### F-01 会话恢复回写旧 token（前端 F 修复）

- **方法**：取 api 容器 Jwt__SecretKey（容器环境变量，与 compose `Jwt__SecretKey` 同源）本地重签真实登录 token：payload 结构不变、仅 exp/iat/nbf 前移（exp=now-1h，有效签名）；与 user/permissions/menus 组装为 `awms.session` 注入 localStorage（本地 CORS 服务 + 浏览器 fetch，JWT 原文经终端脱敏不可见故走浏览器直取）
- **预检**：过期 token 直连 API → `/auth/me` 401；`/auth/refresh` 200 + 新 token（证明签名有效、仅过期）
- **全链路**（两次独立重放均通过）：注入过期会话 → 导航 `/web/master/materials` → 会话恢复：`/auth/me` 401 → 单飞 refresh → 重放成功 → 页面正常渲染（物料列表 33 条，含新建的 M-RT-D5）
- **localStorage 取证**：恢复后 `awms.session.token` 的 exp = 当前时间 + **120 分钟**（= 新 token，AccessTokenExpiry 02:00:00）；过期 token 的 exp = -60 分钟。**localStorage 中 token == 新 token，未被旧 token 回写** ✅
- **后续请求零 401**：恢复后立即执行 keyword=CSZS 搜索（`POST /api/materials/search`）→ 正常返回 2 条；页面无登出、无错误提示 → 不再重复 401/refresh
- 补充说明：本浏览器会话 performance resource timing buffer 为空且 API 容器无请求日志，refresh 精确次数无法从浏览器/服务端取证；以上述行为证据链（token 换新 + 后续零 401 + 两次独立重放一致）判定 F-01 修复生效。修复前旧行为（回写旧 token → 再次 401/refresh 循环，原报告实测 3 次 refresh）未再复现
