## 三、初测 Findings（已修复并复测通过）

### [P0][前端] PDA 扫预建单后无法进入行编辑，收货主链路阻塞

- 初测位置：`frontend/src/modules/pda/PdaHomePage.tsx:928-942`。
- 契约：`docs/api/标签解析.md` 的 `document.lines[].orderLineId`。
- 初测实现错误读取：

```ts
key: line.id,
orderLineId: line.id,
```

- 后端实际响应已确认存在 `document.lines[0].orderLineId`，且不存在 `line.id`。
- 影响：`key/orderLineId` 为 `undefined`，active line 为空，批控属性不可录入，提交无法携带 `orderLineId`，PDA 预建单收货主链路阻塞。
- 修复：按契约读取 `orderLineId`，并补充真实响应形状测试。
- 复测：`PO-20260821-0009` / Order Line `01a024ef-efb9-74df-9d29-5658f9e2fa06` 正确进入行编辑并完成提交。

### [P1][前端] `/pda` 主菜单空白

- 初测位置：`frontend/src/modules/pda/PdaHomePage.tsx:32-36`、`:94-96`。
- 初测问题：
  - 后端菜单 code：`pda.receiving`、`pda.qc`、`pda.putaway`；
  - 前端映射 key：`receiving`、`qc`、`putaway`；
  - 过滤时对后端 code 取不到 action 权限，entries 为空。
- 影响：`/pda` 仅显示仓库头部，作业员无法从主菜单进入三个作业模块。
- 修复：前端菜单映射兼容真实后端 `pda.*` code。
- 复测：页面显示“收货 / 质检 / 上架”。首次仍空白是旧 PWA service worker / 旧标签占用；关闭旧标签后重新进入加载 `assets/index-CCEEMLPy.js`。
