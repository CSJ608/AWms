## 二、修复内容（每项一个 commit 主题）

### F-01（中）会话恢复回写旧 token → 多次 401/refresh
- `src/platform/auth/auth-context.tsx` 会话恢复：用 `apiMe()` 响应里的 `me.token / me.expiresAt` 构建并保存会话（后端 /me 返回请求头中的当前 token），**不得再用恢复前捕获的 `cached.token` 覆盖**。
- 补单测：恢复链路（含 401→refresh→重放）后 `sessionStore` 中 token == me.token（新 token），且后续请求不再触发二次 refresh。

### F-02（低）占位页（/、/inbound、/system）死胡同
- 目标：从菜单进入占位页后仍有导航（侧边栏/返回入口），不再只能靠浏览器后退。
- 实现自选：占位页包 `AppLayout`（保持左侧菜单 + 顶部登出）或在占位页加“返回主数据”入口；与现有布局风格一致。
- 补测试：占位页可渲染且存在返回/导航入口。

### F-03（低）批控列布尔原文 true/false
- 物料列表“批控”列显示为 是/否（中英随语言），不显示 true/false；走 i18n（如 common.yes/no）。
- 同步 mock/测试断言。
