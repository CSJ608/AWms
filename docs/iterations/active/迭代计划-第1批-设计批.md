## 已决议（2026-08-09 用户确认）

| 问题 | 决议 |
|---|---|
| 到货预报 ASN | 本期不做 ASN 管理；收货单保留"来源单据号"自由字段，为未来 ASN 留位 |
| 质检规则 | 保留"收货→质检→上架"三段流，质检默认全检、PDA 一步确认；免检/抽检规则后置 |
| 拍照 | 收货单级别 1-3 张，可选但鼓励（外箱照/破损照/单据照） |
| 打印 | 本期打印收货单（热敏/A4 内置固定模板）；不做模板配置界面 |
| 导入导出 | 标准模板 + 两阶段校验 + 失败明细（物料/仓库/库位/批次）；不做自定义列与方案保存 |
| 权限粒度 | 路由 + 菜单 + 按钮三级，模块注册表驱动；不做字段级/数据级 |
| PDA/Web 分工 | PDA = 收货/质检/上架（扫码为主）；Web = 主数据（含导入导出）/库存查询/打印/拍照查看/权限 |
| 导入导出/打印参考 | 参考 TemplateFrame（C:\work\OpenCode\TemplateFrame）与 Wms4（C:\build\s\Multiway.Logistics.Wms4，应用举例）；按我们自己的架构做，不机械照搬（见 docs/references/参考-TemplateFrame与Wms4-导入导出打印.md） |
| 4 收货场景 | 统一流程 + 数据来源不同（手动/扫单/扫料/双扫） |
| 数量一致性策略 | PO=严格（作废重建，不支持改行）；PR/OT=宽松（按实收，允许超收，差异留痕） |
| 标签规范 | 已定稿 v0.4（AWMS1:+JSON；t/s/u/b/rt/rc/rb/pd/ex/q/ty/d/wh；名称不入码） |
| 单据存储模型 | 统一表 + 类型路由（ADR-003 已采纳）；ty=PO/PR/OT |
