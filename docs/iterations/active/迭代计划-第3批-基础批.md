# 迭代计划 — 第3批：基础批（框架 + 主数据 + 查询平台 + 导入导出）

> 状态：**草案 v0.1（2026-08-10，待用户确认）**。
> 依据：锁定契约（docs/api/ 全套）、界面规格（通用列表与表单/基础数据物料）、ADR-001~005、规章制度 §八（异地工作区协作 8.8）。

## 目标
跑通“框架 + 主数据”：登录/权限/菜单（模块注册表）、主数据 CRUD（含 searchCode）、查询平台（filter DSL/字段元数据/keyword）、物料导入导出、前端骨架与基础页面（通用列表/表单 + 物料页）。
**明确不做**：收货链（第 4 批）、PDA 作业（第 4 批）、打印/附件业务（第 4 批）、工作台聚合与库存查阅（第 5 批）。

## 工作区与配合（规章制度 8.8）
- 前端：C:\build\f（clone/pull 最新 main → 开分支 feat/frontend-3）
- 后端：C:\build\b（clone/pull 最新 main → 开分支 feat/backend-3）
- docs/ 只读；发现问题写问题清单；完工按汇报模板提交（docs/reviews/ 或 PR 描述）
- 完工后：用户开新会话 → 协调者（Codex）集成回顾 → 问题清单 → 裁决 → 修复 → 合并 main → 批验收
