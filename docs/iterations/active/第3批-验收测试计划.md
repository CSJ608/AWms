# 第3批-验收测试计划（测试环境联调迭代）

> 出具人：协调者（Codex）｜日期：2026-08-11
> 目标：确保第3批交付功能在测试环境（web 8082 / api 5081 / db 5434）全部可运行；通过项记录为已通过，失败项记录初步原因但**不修改代码**；前置不满足则汇总阻塞并开启修复迭代。
> 执行人：前端（只测只报）；复核：协调者；裁决：用户。
> 环境：http://localhost:8082，账号 admin / Admin@2026Dev（口令见 deploy/.env，测试专用）。

## 一、执行规则

1. 状态三态：✅ 通过 / ❌ 失败（功能进入但行为不符，附初步原因分析）/ ⛔ 阻塞（前置不满足，无法进入）。
2. 每项记录证据：URL、请求/响应、截图、DB 查询（psql：`docker exec awms-test-db-1 psql -U awms -d awms_test`）。
3. **不修改任何代码**（前端/后端/契约均不动）；发现问题只记录。
4. **前置冒烟**：先完成 A 组（登录/会话）与 B 组（路由/导航）；若 A1/A2 或 B2 无法通过 → **立即停止**，写《验收阻塞汇总》并回报，不继续测后续。
5. 完成后写《第3批-验收测试报告》（frontend/第3批-验收测试报告.md），逐条填状态/证据/原因。

## 二、功能目标清单

### A. 登录与会话（前置）
- [ ] A1 访问 http://localhost:8082/ → 未登录跳 /login，登录页正常渲染（无 404）

- [ ] A4 停用账号登录 → 提示 USER_DISABLED
