## 二、修复内容（C4①，一个主题可分多个 commit）

**问题**：OPERATOR 登录后 `/auth/me` 返回 menus.web 4 项（应仅 inbound）。初步原因：MenuDefinition 种子未设 `RequiredPermissionCode`，`BuildMenuTree` 的过滤条件恒不成立。

**修复**：
1. `AWms.Infrastructure/Data/AWmsDbContext.cs` 种子为菜单补 `RequiredPermissionCode`：
   - `menu.dashboard` → 不设（所有登录用户可见，占位页）；
   - `menu.inbound` → `route.inbound`；
   - `menu.master-data` → `route.master-data`；
   - `menu.system` → `route.system`；
   - `pda.receiving` → `route.inbound`。
2. 生成迁移：`dotnet ef migrations add AddMenuRequiredPermissions`（禁 EnsureCreated；SQL 随代码提交供 review）。
3. 补测试（单元或集成，断言 `/auth/me` 的 menus 过滤）：
   - OPERATOR：menus.web 仅含 dashboard + inbound（**不含 master-data/system**）；pda 含 receiving；
   - SUPERVISOR：含 dashboard + inbound + master-data（不含 system）；
   - SYSTEM_ADMIN：全量 4 项。
4. 验证：`dotnet build` 0 error 0 warning；`dotnet test AWms.slnx` 单元+集成全绿 0 Skip（Testcontainers PG）。
