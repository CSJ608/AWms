# 标签解析接口契约（第 4 批修订草案 v0.2）

> 状态：**第 4 批修订草案 v0.2（2026-08-20，待前后端复核）**。基于已锁定 v0.1 补齐单据上下文、批次候选和唯一码数量；复核无异议后重新锁定。
> 定位：PDA 扫码的**统一入口**——扫任意码，后端解析并返回识别结果（含校验上下文）。前端不做标签解析逻辑（离线后置）。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/scan/parse | 解析扫码内容（含可选上下文校验） |

## 二、请求

```json
{
  "content": "AWMS1:{\"v\":1,\"t\":\"S\",\"s\":\"MAT-001\",\"ol\":\"<orderLineId>\"}",
  "context": {
    "inboundOrderId": "uuid",   // 可选：当前收货上下文（扫单后）
    "warehouseId": "uuid"       // 可选
  }
}
```

## 三、响应（ScanResult）

```json
{
  "type": "SKU_LABEL",
  "labelType": "S",
  "material": {
    "materialId": "uuid", "materialCode": "MAT-001", "materialName": "螺母 M6",
    "batchControlled": true, "labelType": "SKU", "defaultUom": "CT",
    "defaultQtyPerLabel": "10.0000"
  },
  "uniqueCode": null,
  "batch": null,
  "batchProps": null,
  "quantity": null,
  "document": {
    "inboundOrderId": "uuid", "docType": "PO", "docNo": "PO-20260810-0001",
    "warehouseId": "uuid", "warehouseCode": "WH-01", "status": "CONFIRMED",
    "lines": [
      { "orderLineId": "uuid", "lineNo": 3,
        "materialId": "uuid", "materialCode": "MAT-001", "materialName": "螺母 M6",
        "expectedQty": "200.0000", "receivedQty": "0.0000", "remainingQty": "200.0000",
        "uniqueCodes": [] }
    ]
  },
  "source": { "sourceType": "SUPPLIER", "sourceCode": "SUP-001", "sourceName": "华东五金" },
  "external": null,
  "warnings": []
}
```

**type 取值**：SKU_LABEL / UNIQUE_LABEL / BATCH_LABEL / DOCUMENT_QR / EXTERNAL_BARCODE / UNKNOWN。

### 3.1 条件字段

| 字段 | 出现条件 | 内容 |
|---|---|---|
| `material` | S/U/B 或可识别外部条码 | 始终包含 `defaultQtyPerLabel`，可为 null |
| `uniqueCode` | U | `{ code, status, quantity, receivedAt? }`；quantity 为该码代表数量 |
| `batch` | B | 已存在内部批次的 ID、批次号及来源批号/生产日期/效期 |
| `batchProps` | S 或可解析外部条码 | `{ sourceBatchNo?, productionDate?, expiryDate?, sourceType?, sourceCode? }`，供收货请求原样带回 |
| `quantity` | U/B 或外部条码含数量 | decimal 字符串；U 与 `uniqueCode.quantity` 一致 |
| `document` | D，或 S 带 `ol` | D 返回单据头和全部行；S+ol 返回单据头和命中的一个行元素 |
| `source` | S 带合法 `rt/rc` | 规范化为 `{ sourceType: SUPPLIER/WORKSHOP, sourceCode, sourceName }`；标签 rt 的 S/W 分别映射为 SUPPLIER/WORKSHOP |
| `external` | 非 AWMS1 且可识别 | 外部条码原始格式和结构化解析结果 |
| `warnings` | 有上下文风险时 | `{ code, message, blocking }[]`；warning 本身不改变 HTTP 200 |
| `message` | UNKNOWN | 可直接展示的“未识别，请手动输入”提示 |

`document.lines[].uniqueCodes` 与入库单详情同构；非唯一码物料为空数组。前端不得只依赖 `docNo` 再猜测或搜索单据 ID。

## 四、解析规则（依据标签规范 v0.14）

### 1. AWMS1 前缀
- 解析 JSON；非法 JSON → 400 SCAN_PARSE_ERROR。
- 按 `t` 分类：

| t | 返回内容 |
|---|---|
| S 外标签 | material（按 s 查）；带 ol → document（单据头+命中行）；带 rt/rc → source；rb/pd/ex/rt/rc → batchProps |
| U 唯一码 | material + uniqueCode + quantity；查 UNRECEIVED/RECEIVED；有收货上下文时校验是否在本单清单 |
| B 批次标签 | material + batch + quantity（q）；batch 含 sourceBatchNo/productionDate/expiryDate |
| D 单据码 | 按 ty+d 路由到统一入库单服务 → document（含 `inboundOrderId`、仓库、状态和全部行）；context 校验状态/仓库 |

### 2. 非 AWMS1（外部条码）
- 尽力解析：EAN-13 / Code128 / GS1 AI（(01)GTIN、(10)批次、(11)生产日期、(15)效期、(30)数量）。
- 成功 → type=EXTERNAL_BARCODE + external（含 code/format/parsed 字段）；解析不出 → type=UNKNOWN。

### 3. 未知
- type=UNKNOWN + message（"未识别，请手动输入"）——**200 返回**（业务非服务端错误）。

## 五、上下文校验（warnings）

- 唯一码不在当前单据清单 → `UNIQUE_CODE_NOT_IN_ORDER`，blocking=true；
- 唯一码已收过 → `UNIQUE_CODE_ALREADY_RECEIVED`，blocking=true；
- 单据已作废/状态不允许 → `ORDER_VOIDED/ORDER_STATUS_INVALID`，blocking=true；
- 单据仓库与 context.warehouseId 不同 → `WAREHOUSE_MISMATCH`，blocking=true；
- 物料不在当前单据行 → `ORDER_LINE_MISMATCH`，blocking=true；
- 标签来源与当前 PO/PR 单据来源不一致 → `SOURCE_MISMATCH`，blocking=true。
- 解析接口仍返回 HTTP 200；PDA 对 `blocking=true` 必须阻断进入/继续当前动作，对 `blocking=false` 只提示。最终业务动作接口必须重复校验，不能信任前端已拦截。

## 六、业务规则

1. **后端统一解析**（前端只传 content + context）：单一实现、可做校验；离线后置。
2. **性能**：扫码高频，接口只读；物料/批次/来源查询走缓存；唯一码按 code 索引。
3. 权限：登录即可用（按角色操作权限后续接口把关）。
4. 未知码返回 200 + UNKNOWN（不是错误）；AWMS1 前缀损坏 → 400 SCAN_PARSE_ERROR（0x050301? 不，归通用/系统——新增 SCAN_PARSE_ERROR 0x000008 通用）。

## 七、错误码

SCAN_PARSE_ERROR（400，AWMS1 前缀但内容损坏）、VALIDATION_ERROR、UNAUTHORIZED、FORBIDDEN。
