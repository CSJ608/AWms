# 标签解析接口契约（已锁定 v0.1）

> 状态：**已锁定 v0.1**。第 2 批 C-05 锁定；待第 4 批收货链实现。
> 定位：PDA 扫码的**统一入口**——扫任意码，后端解析并返回识别结果（含校验上下文）。前端不做标签解析逻辑（离线后置）。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/scan/parse | 解析扫码内容（含可选上下文校验） |

## 二、请求

```json
{
  "content": "AWMS1:{\"v\":1,\"t\":\"S\",\"s\":\"MAT-001\",\"ol\":\"<orderLineId>\"}",
  "context": {
    "inboundOrderId": "uuid",   // 可选：当前收货上下文（扫单后）
    "warehouseId": "uuid"       // 可选
  }
}
```

## 三、响应（ScanResult）

```json
{
  "type": "SKU_LABEL",
  "labelType": "S",
  "material": {
    "materialId": "uuid", "materialCode": "MAT-001", "materialName": "螺母 M6",
    "batchControlled": true, "labelType": "SKU", "defaultUom": "CT",
    "defaultQtyPerLabel": "10.0000"
  },
  "uniqueCode": null,
  "batch": null,
  "document": {
    "docType": "PO", "docNo": "PO-20260810-0001",
    "orderLineId": "<orderLineId>", "orderLineNo": 3,
    "expectedQty": "200.0000"
  },
  "source": { "sourceType": "SUPPLIER", "sourceCode": "SUP-001", "sourceName": "华东五金" },
  "external": null,
  "warnings": []
}
```

**type 取值**：SKU_LABEL / UNIQUE_LABEL / BATCH_LABEL / DOCUMENT_QR / EXTERNAL_BARCODE / UNKNOWN。

## 四、解析规则（依据标签规范 v0.14）

### 1. AWMS1 前缀
- 解析 JSON；非法 JSON → 400 SCAN_PARSE_ERROR。
- 按 `t` 分类：

| t | 返回内容 |
|---|---|
| S 外标签 | material（按 s 查）；带 ol → document.orderLine（按 ol 解析行）；带 rt/rc → source（查名称）；rb/pd/ex → 作为批次属性候选（随上下文返回） |
| U 唯一码 | material + uniqueCode；查唯一码状态（UNRECEIVED/RECEIVED）放入 warnings/字段；若 context.inboundOrderId → 校验是否在本单清单（不在 → warning） |
| B 批次标签 | material + batch（按 b 查，含 sourceBatchNo/productionDate/expiryDate）；q 数量 |
| D 单据码 | 按 ty+d 路由到单据服务（统一表，ADR-003）→ document（含行列表）；context 校验单据状态（VOIDED → warning） |

### 2. 非 AWMS1（外部条码）
- 尽力解析：EAN-13 / Code128 / GS1 AI（(01)GTIN、(10)批次、(11)生产日期、(15)效期、(30)数量）。
- 成功 → type=EXTERNAL_BARCODE + external（含 code/format/parsed 字段）；解析不出 → type=UNKNOWN。

### 3. 未知
- type=UNKNOWN + message（"未识别，请手动输入"）——**200 返回**（业务非服务端错误）。

## 五、上下文校验（warnings）

- 唯一码不在当前单据清单 → warning（UNIQUE_CODE_NOT_IN_ORDER 语义）；
- 唯一码已收过 → warning（UNIQUE_CODE_ALREADY_RECEIVED）；
- 单据已作废/状态不允许 → warning；
- 物料不在当前单据行（带 context）→ warning（ORDER_LINE_MISMATCH 语义）。
- **warning 不阻断**（PDA 据此提示；是否拦截由业务动作接口决定）。

## 六、业务规则

1. **后端统一解析**（前端只传 content + context）：单一实现、可做校验；离线后置。
2. **性能**：扫码高频，接口只读；物料/批次/来源查询走缓存；唯一码按 code 索引。
3. 权限：登录即可用（按角色操作权限后续接口把关）。
4. 未知码返回 200 + UNKNOWN（不是错误）；AWMS1 前缀损坏 → 400 SCAN_PARSE_ERROR（0x050301? 不，归通用/系统——新增 SCAN_PARSE_ERROR 0x000008 通用）。

## 七、错误码

SCAN_PARSE_ERROR（400，AWMS1 前缀但内容损坏）、VALIDATION_ERROR、UNAUTHORIZED、FORBIDDEN。
