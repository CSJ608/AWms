# 物料接口契约（草案 v0.3）

> 状态：**草案 v0.3（2026-08-10）**。v0.3：新增 searchCode（助记码）与 keyword 搜索（code/name/searchCode 模糊匹配）。
> 依据：通用规范 v1.6、数据模型 v0.4、标签规范 v0.12。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/materials | 分页列表 + 筛选（含 keyword） |
| POST | /api/materials | 新建（幂等） |
| PUT | /api/materials/{id} | 编辑（code 只读） |
| DELETE | /api/materials/{id} | 删除（引用保护） |

## 二、DTO

```json
{
  "id": "uuid",
  "code": "MAT-001",
  "name": "螺母 M6",
  "searchCode": "LM",
  "batchControlled": true,
  "labelType": "SKU",
  "defaultUom": "CT",
  "defaultQtyPerLabel": "10.0000",
  "status": "ENABLED",
  "createdAt": "2026-08-10T00:00:00Z",
  "updatedAt": "2026-08-10T00:00:00Z"
}
```

## 三、端点详述

### GET /api/materials
- 固定参数：`code`（模糊）、`name`（模糊）、`labelType`、`status`、`page`、`pageSize`。
- **`keyword`（新增）**：模糊匹配 **code / name / searchCode** 三者（引用选择器快捷搜索用）。
- 支持 filter DSL；**字段白名单**：code、name、searchCode、batchControlled、labelType、defaultUom、defaultQtyPerLabel、status、createdAt、updatedAt。
- **排序白名单**：code、name、status、updatedAt；默认 code asc。
- 响应 200：`{items,total,page,pageSize}`。

### POST /api/materials
- 请求：`{ code, name, searchCode?, batchControlled, labelType, defaultUom, defaultQtyPerLabel?, status? }`。
- 响应 201。错误：VALIDATION_ERROR（400）、MATERIAL_CODE_DUPLICATED（409）。

### PUT /api/materials/{id}
- 请求：`{ name, searchCode?, batchControlled, labelType, defaultUom, defaultQtyPerLabel?, status }`（code 不可改）。
- 响应 200。错误：MATERIAL_NOT_FOUND（404）、VALIDATION_ERROR。

### DELETE /api/materials/{id}
- 响应 204。错误：MATERIAL_NOT_FOUND（404）、MATERIAL_IN_USE（409）。

## 四、校验与业务规则

- code：必填、1..64、唯一、创建后不可改。
- name：必填、1..128。
- **searchCode（可选）**：助记码/搜索码，1..32，用于 keyword 快捷搜索（如拼音首字母）。
- labelType ∈ NONE/SKU/UNIQUE；defaultUom ∈ UOM；defaultQtyPerLabel >0 可选。
- 删除保护：被引用拒绝。

## 五、错误码

VALIDATION_ERROR、MATERIAL_CODE_DUPLICATED、MATERIAL_NOT_FOUND、MATERIAL_IN_USE、UNAUTHORIZED、FORBIDDEN。
