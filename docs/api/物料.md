# 物料接口契约（草案 v0.2）

> 状态：**草案 v0.2（2026-08-10）**。v0.2：新增可选字段 defaultQtyPerLabel（默认每标签数量）。
> 依据：通用规范 v1.3、数据模型 v0.4、标签规范 v0.12。
> 界面词：物料；标签类型说明：无=手动输入、SKU码=非唯一连扫、唯一码=逐件防重。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/materials | 分页列表 + 筛选 |
| POST | /api/materials | 新建（幂等） |
| PUT | /api/materials/{id} | 编辑（code 只读） |
| DELETE | /api/materials/{id} | 删除（引用保护） |

## 二、DTO

```json
{
  "id": "uuid",
  "code": "MAT-001",
  "name": "螺母 M6",
  "batchControlled": true,
  "labelType": "SKU",
  "defaultUom": "CT",
  "defaultQtyPerLabel": "10.0000",
  "status": "ENABLED",
  "createdAt": "2026-08-10T00:00:00Z",
  "updatedAt": "2026-08-10T00:00:00Z"
}
```

## 三、端点详述

### GET /api/materials
- 筛选：`code`（模糊）、`name`（模糊）、`labelType`、`status`、`page`、`pageSize`。
- 响应 200：`{ items: [MaterialItem], total, page, pageSize }`。

### POST /api/materials
- 请求：`{ code, name, batchControlled, labelType, defaultUom, defaultQtyPerLabel?, status? }`。
- 响应 201：MaterialItem。
- 错误：VALIDATION_ERROR（400）、MATERIAL_CODE_DUPLICATED（409）。

### PUT /api/materials/{id}
- 请求：`{ name, batchControlled, labelType, defaultUom, defaultQtyPerLabel?, status }`（code 不可改）。
- 响应 200：MaterialItem。错误：MATERIAL_NOT_FOUND（404）、VALIDATION_ERROR。

### DELETE /api/materials/{id}
- 响应 204。错误：MATERIAL_NOT_FOUND（404）、MATERIAL_IN_USE（409，引用保护）。

## 四、校验与业务规则

- code：必填、1..64、唯一、创建后不可改。
- name：必填、1..128。
- labelType ∈ NONE / SKU / UNIQUE（决定 PDA 扫码行为）。
- defaultUom ∈ UOM（CT/PC/BOX/KG/G/L/M）。
- **defaultQtyPerLabel（可选）**：默认每标签数量（decimal 字符串）；空=不拆分（整行 1 张）；>0 时用于标签打印拆分默认值与 PDA 连扫累加默认值（标签规范第七节，待现场验证）。
- 删除保护：被批次/单据/库存引用时拒绝。

## 五、错误码

VALIDATION_ERROR、MATERIAL_CODE_DUPLICATED、MATERIAL_NOT_FOUND、MATERIAL_IN_USE、UNAUTHORIZED、FORBIDDEN。
