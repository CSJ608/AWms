# 来源接口契约（已锁定 v0.4）

> 状态：**已锁定 v0.4**。第 2 批 C-05 锁定；第 3 批已实现并完成联调，v0.4 明确 searchCode 不要求唯一。
> 依据：通用规范 v1.7、数据模型 v0.4、标签规范 v0.12（rt/rc 查名称）。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/sources/search | 来源列表（keyword/固定参数/filter/sort，通用规范 2.10） |
| GET | /api/sources | 引用选择器快捷搜索（?keyword=&pageSize=） |
| POST | /api/sources | 新建来源 |
| PUT | /api/sources/{id} | 编辑（type/code 只读） |
| DELETE | /api/sources/{id} | 删除（引用保护） |

## 二、DTO

```json
{ "id": "uuid", "type": "SUPPLIER", "code": "SUP-001", "name": "华东五金", "searchCode": "HDWJ", "status": "ENABLED", "createdAt": "..." }
```

## 三、端点详述

### POST /api/sources/search
- 请求体：`{ keyword?, type?, status?, filter?, sort?, page?, pageSize? }`（keyword 匹配 code/name/searchCode）。
- 支持 filter DSL；**字段白名单**：type、code、name、searchCode、status、createdAt。
- **排序白名单**：code、name、status；默认 code asc（服务端追加 id 兜底，通用规范 2.10 v2.1）。

### POST /api/sources
- 请求：`{ type, code, name, searchCode?, status? }`。响应 201。错误：SOURCE_CODE_DUPLICATED（409）、VALIDATION_ERROR。

### PUT /api/sources/{id}
- 请求：`{ name, searchCode?, status }`。响应 200。错误：SOURCE_NOT_FOUND（404）。

### DELETE /api/sources/{id}
- 响应 204。错误：SOURCE_NOT_FOUND（404）、SOURCE_IN_USE（409）。

## 四、校验与业务规则

- type ∈ SUPPLIER/WORKSHOP；(type, code) 同类型唯一、不可改。
- name 必填 1..128；searchCode 可选 1..32，**不要求唯一**（重复允许）。
- 用途：标签 rt/rc 解析按 (type, code) 查名称；外标签留档。

## 五、错误码

SOURCE_CODE_DUPLICATED、SOURCE_NOT_FOUND、SOURCE_IN_USE、VALIDATION_ERROR、UNAUTHORIZED、FORBIDDEN。
