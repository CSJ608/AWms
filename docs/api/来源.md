# 来源接口契约（草案 v0.1）

> 状态：**草案 v0.1（2026-08-10）**。依据：通用规范 v1.0、数据模型 v0.1、标签规范 v0.4（rt/rc 查名称）。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/sources | 列表（默认全量，按 type 筛） |
| POST | /api/sources | 新建来源（供应商/生产车间） |
| PUT | /api/sources/{id} | 编辑（type/code 只读） |
| DELETE | /api/sources/{id} | 删除（引用保护） |

## 二、DTO

```json
{ "id": "uuid", "type": "SUPPLIER", "code": "SUP-001", "name": "华东五金", "status": "ENABLED", "createdAt": "..." }
```

## 三、端点详述

### GET /api/sources
- 参数：`type`（SUPPLIER/WORKSHOP）、`status`、`page`、`pageSize`（默认全量）。
- 响应 200：分页结构。

### POST /api/sources
- 请求：`{ type, code, name, status? }`。
- 响应 201。错误：SOURCE_CODE_DUPLICATED（409，同类型内重复）、VALIDATION_ERROR（400）。

### PUT /api/sources/{id}
- 请求：`{ name, status }`（type/code 不可改）。
- 响应 200。错误：SOURCE_NOT_FOUND（404）。

### DELETE /api/sources/{id}
- 响应 204。错误：SOURCE_NOT_FOUND（404）、SOURCE_IN_USE（409，被批次/标签引用禁止删除）。

## 四、校验与业务规则

- type ∈ SUPPLIER / WORKSHOP。
- (type, code)：同类型内唯一、1..64、不可改。
- name：必填 1..128。
- 用途：标签 rt/rc 解析时按 (type, code) 查名称显示；外标签/批次属性留档。

## 五、错误码

SOURCE_CODE_DUPLICATED、SOURCE_NOT_FOUND、SOURCE_IN_USE、VALIDATION_ERROR、UNAUTHORIZED、FORBIDDEN。
