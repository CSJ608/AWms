# 库存接口契约（草案 v0.2，C-03）

> 状态：**草案 v0.3（2026-08-10）**。v0.2：新增汇总端点 /api/stocks/summary；列表支持 filter DSL 与 sort 白名单（通用规范 2.10）。
> 依据：通用规范 v1.4、数据模型 v0.4、概念设计 v1.0、术语对照表。
> 界面词：库存 / 库位库存 / 库存流水 / 可用库存。本期只读查询（移库/出库/盘点/冻结/预留后置）。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/stocks | 库存（主体）分页列表 |
| GET | /api/stocks/summary | **汇总：按 仓库+物料 聚合（含批次展开入口）** |
| GET | /api/stocks/{id} | 库存主体详情 |
| GET | /api/location-stocks | 库位库存（物理库存）分页列表 |
| GET | /api/stock-ledgers | 库存流水分页列表 |
| GET | /api/stock-ledgers/{id} | 流水详情 |
| GET | /api/stock-ledgers/{id}/group | 同事务组流水（复式记账来龙去脉） |

## 三、端点详述

### GET /api/stocks
- 固定参数：`warehouseId`、`materialKeyword`、`batchId`、`status`、`page`、`pageSize`。
- 高级筛选：支持 `filter` DSL（通用规范 2.10）。
- **字段白名单**：warehouseId、materialId、materialCode、materialName、batchId、batchNo、status、totalQty、createdAt、updatedAt。
- **排序白名单**：materialCode、materialName、totalQty、status、updatedAt、createdAt；默认 materialCode asc。
- 响应 200：`{items,total,page,pageSize}`；totalQty=跨库位合计。

### GET /api/stocks/summary
- 固定参数：`warehouseId`、`materialKeyword`、`status`、`page`、`pageSize`。
- 响应 200：StockSummaryItem[]（按 仓库+物料 聚合：totalQty=Σ主体合计，batchCount=批次个数，statusDist=状态分布）。
- **批次展开**：点击物料 → 调 GET /api/stocks?warehouseId=&materialId= 查看该物料各批次明细。

### GET /api/stocks/{id}
- 响应 200：StockItem。错误：SUBJECT_NOT_FOUND（404）。

### GET /api/location-stocks
- 固定参数：`warehouseId`、`locationId`、`materialKeyword`、`batchId`、`status`、`page`、`pageSize`。
- 支持 filter DSL；**字段白名单**：warehouseId、locationId、locationCode、subjectId、materialId、materialCode、materialName、batchId、batchNo、status、quantity、updatedAt。
- **排序白名单**：locationCode、materialCode、quantity、status、updatedAt；默认 locationCode asc。
- 响应 200：分页结构。错误：LOCATION_NOT_FOUND（404，若传 locationId）。

### GET /api/stock-ledgers
- 固定参数：`warehouseId`、`materialKeyword`、`batchId`、`locationId`、`reason`、`dateFrom`、`dateTo`、`txnGroupId`、`page`、`pageSize`。
- 支持 filter DSL；**字段白名单**：warehouseId、materialId、materialCode、materialName、batchId、batchNo、locationId、locationCode、reason、occurredAt、quantity、operatorId、txnGroupId。
- **排序白名单**：occurredAt、materialCode、quantity；默认 occurredAt desc。

### GET /api/stock-ledgers/{id}
- 响应 200：LedgerItem。错误：LEDGER_LINE_NOT_FOUND（404）。

### GET /api/stock-ledgers/{id}/group
- 响应 200：同事务组流水列表（按 seq 排序）。

## 四、业务规则

1. totalQty 聚合（跨库位）；流水可重建物理库存。
2. 可用量口径（本期简化）：可用库存=状态 AVAILABLE 的主体（KPI 用主体数 total）；完整公式后置。
3. 物理库存 version 返回；写冲突抛 VERSION_CONFLICT。
4. 非批控物料 batchNo=DEFAULT（界面显示"默认批次"）。
5. filter/sort 白名单外字段 → 400 VALIDATION_ERROR；全部参数化。

## 五、字段元数据（可筛选字段，2026-08-10）

> 供前端 SearchField[] 与运行时元数据端点使用（通用规范 2.10）。

### /api/stocks

| field | type | operators | options |
|---|---|---|---|
| warehouseId | ref(warehouses) | eq/in | 仓库列表 |
| materialId | ref(materials) | eq/in | 物料列表 |
| materialCode | string | eq/contains/startsWith/in | — |
| materialName | string | eq/contains | — |
| batchId | ref(batches) | eq/in | 该物料批次列表 |
| batchNo | string | eq/contains | — |
| status | enum | eq/in/neq | PENDING_INSPECTION/AVAILABLE/FROZEN |
| totalQty | decimal | eq/gt/gte/lt/lte/between | — |
| createdAt / updatedAt | datetime | eq/gt/gte/lt/lte/between | — |

### /api/location-stocks

| field | type | operators | options |
|---|---|---|---|
| warehouseId | ref(warehouses) | eq/in | 仓库列表 |
| locationId / locationCode | ref/uuid, string | eq/in / eq/contains | 库位列表 |
| materialId / materialCode / materialName | ref/uuid, string | 同 stocks | — |
| batchId / batchNo | 同 stocks | — | — |
| status | enum | eq/in/neq | 同 stocks |
| quantity | decimal | 比较+between | — |
| updatedAt | datetime | 比较+between | — |

### /api/stock-ledgers

| field | type | operators | options |
|---|---|---|---|
| warehouseId | ref(warehouses) | eq/in | 仓库列表 |
| materialId / materialCode / materialName | 同 stocks | — | — |
| batchId / batchNo | 同 stocks | — | — |
| locationId / locationCode | 同 location-stocks | — | — |
| reason | enum | eq/in | RECEIPT/QUALITY_CHECK/PUTAWAY/…（枚举文档） |
| occurredAt | datetime | 比较+between | — |
| quantity | decimal | 比较+between | — |
| operatorId | ref(users) | eq/in | 用户列表 |
| txnGroupId | uuid | eq | — |
