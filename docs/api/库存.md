# 库存接口契约（草案 v0.1，C-03）

> 状态：**草案 v0.1（2026-08-10）**。依据：通用规范 v1.3、数据模型 v0.4、概念设计 v1.0、术语对照表。
> 界面词：库存（库存主体）/ 库位库存（物理库存）/ 库存流水 / 可用库存。
> 本期为**只读查询**：移库/出库/盘点/冻结/预留本期不提供端点（后置）。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/stocks | 库存（主体）分页列表 |
| GET | /api/stocks/{id} | 库存主体详情 |
| GET | /api/location-stocks | 库位库存（物理库存）分页列表 |
| GET | /api/stock-ledgers | 库存流水分页列表 |
| GET | /api/stock-ledgers/{id} | 流水详情 |
| GET | /api/stock-ledgers/{id}/group | 同事务组流水（复式记账来龙去脉） |

## 二、DTO

### StockItem（库存主体）
```json
{
  "id": "uuid",
  "warehouseId": "uuid", "warehouseCode": "WH-01",
  "materialId": "uuid", "materialCode": "MAT-001", "materialName": "螺母 M6",
  "batchId": "uuid", "batchNo": "260810001",
  "status": "AVAILABLE",
  "uom": "CT",

```

## 三、端点详述

### GET /api/stocks
- 筛选：`warehouseId`、`materialKeyword`（编码/名称模糊）、`batchId`、`status`（PENDING_INSPECTION/AVAILABLE/FROZEN）、`page`、`pageSize`。
- 响应 200：`{items,total,page,pageSize}`；items 含 totalQty（跨库位合计）。
- 用途：库存页、工作台 KPI（待质检=status=PENDING_INSPECTION 的 total；可用SKU=status=AVAILABLE 的 total，前端取 pageSize=1 的 total）。

### GET /api/stocks/{id}
- 响应 200：StockItem。错误：SUBJECT_NOT_FOUND（404）。

### GET /api/location-stocks
- 筛选：`warehouseId`、`locationId`、`materialKeyword`、`batchId`、`status`、`page`、`pageSize`。
- 响应 200：分页结构。错误：LOCATION_NOT_FOUND（404，若传 locationId）。

### GET /api/stock-ledgers
- 筛选：`warehouseId`、`materialKeyword`、`batchId`、`locationId`、`reason`、`dateFrom`、`dateTo`（ISO 日期）、`txnGroupId`、`page`、`pageSize`。
- 响应 200：分页结构，默认 occurredAt 倒序。

### GET /api/stock-ledgers/{id}
- 响应 200：LedgerItem。错误：LEDGER_LINE_NOT_FOUND（404）。

### GET /api/stock-ledgers/{id}/group
- 响应 200：同事务组流水列表（按 seq 排序）——复式记账的完整来龙去脉（收货=外部操作组内≠0；质检/上架=内部操作组内=0）。

## 四、业务规则

1. **totalQty 聚合**：后端对库存主体 SUM 其物理库存（跨库位）；流水可重建物理库存（概念 v1.0）。
2. **可用量口径（本期简化）**：可用库存 = 状态 AVAILABLE 的主体（数量合计可选，KPI 用主体数 total）；冻结/盘点锁定/预留扣减的完整公式后置（概念 §八）。
3. **版本号**：物理库存 version 返回给前端（展示/调试）；写操作冲突时后端抛 VERSION_CONFLICT（本期写操作仅在收货/上架内部）。
4. **非批控物料**：batchNo=DEFAULT（界面显示"默认批次"）。
5. 流水只追加，不改不删；数量有符号字符串。

## 五、错误码

SUBJECT_NOT_FOUND、LOCATION_NOT_FOUND、LEDGER_LINE_NOT_FOUND、VALIDATION_ERROR、UNAUTHORIZED、FORBIDDEN。
