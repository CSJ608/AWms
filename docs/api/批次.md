# 批次接口契约（草案 v0.1）

> 状态：**草案 v0.1（2026-08-10）**。依据：通用规范 v1.0、数据模型 v0.1、标签规范 v0.4。
> 界面词：批次号（内部）/ 来源批号（外部）。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/materials/{materialId}/batches | 某物料批次列表（全量） |
| POST | /api/materials/{materialId}/batches | 手动预建批次（供预建单指定） |
| GET | /api/batches/{id} | 批次详情 |

> DELETE 本期不提供：批次生命周期后置（收货时系统生成；生产退料复用原批次）。

## 二、DTO

```json
{
  "id": "uuid", "materialId": "uuid", "materialCode": "MAT-001",
  "batchNo": "B260809-001",
  "sourceBatchNo": "PRD-260809-01",
  "sourceType": "WORKSHOP", "sourceCode": "WS-01",
  "productionDate": "2026-08-09", "expiryDate": null,
  "status": "ACTIVE", "createdAt": "..."
}
```

## 三、端点详述

### GET /api/materials/{materialId}/batches
- 参数：`status`；默认全量（pageSize=0）。
- 响应 200：`{items,total,page,pageSize}`。错误：MATERIAL_NOT_FOUND（404）。

### POST /api/materials/{materialId}/batches
- 请求：`{ batchNo, sourceBatchNo?, sourceType?, sourceCode?, productionDate?, expiryDate? }`。
- 响应 201。错误：BATCH_NO_DUPLICATED（409）、MATERIAL_NOT_FOUND（404）、VALIDATION_ERROR（含"非批控物料不允许手动建批次"）。
- 说明：非批控物料使用系统默认批次（DEFAULT），不允许手动创建；收货时内部批次由系统生成（另有内部逻辑，不走本端点）。

### GET /api/batches/{id}
- 响应 200。错误：BATCH_NOT_FOUND（404）。

## 四、校验与业务规则

- batchNo：全局唯一、1..64、不可改。
- sourceType ∈ SUPPLIER / WORKSHOP（与 sourceCode 成对，用于标签 rt/rc 查名称留档）。
- productionDate / expiryDate：yyyy-MM-dd。
- 生产退料复用原批次：通过扫描批次标签（t=B）识别原内部批次，不走新建（收货链内部逻辑）。

## 五、错误码

BATCH_NO_DUPLICATED、BATCH_NOT_FOUND、MATERIAL_NOT_FOUND、VALIDATION_ERROR、UNAUTHORIZED、FORBIDDEN。
