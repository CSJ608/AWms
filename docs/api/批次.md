# 批次接口契约（草案 v0.2）

> 状态：**草案 v0.2（2026-08-10）**。v0.2：批次改为**系统自动建立**，删除手动创建/删除端点。
> 依据：通用规范 v1.0、数据模型 v0.1、标签规范 v0.4。
> 界面词：批次号（内部）/ 来源批号（外部）。

## 一、批次的生命周期（2026-08-10 确认）

- **批次全部由系统自动建立**：
  - 收货时生成内部批次号（含来源批号/生产日期等属性，按标签/录入带入）；
  - 生产退料扫描原批次标签（t=B）时**复用原批次**；
  - 非批控物料使用系统默认批次（DEFAULT）。
- 用户/前端**不手动创建、不删除批次**；本期不提供 POST/DELETE 端点。
- 预建单如需指定"期望来源批号/生产日期"，作为预建单行的期望信息（后续扩展，不在本契约）。

## 二、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/materials/{materialId}/batches | 某物料批次列表（全量） |
| GET | /api/batches/{id} | 批次详情 |

## 三、DTO

```json
{
  "id": "uuid", "materialId": "uuid", "materialCode": "MAT-001",
  "batchNo": "B20260810-0001",
  "sourceBatchNo": "PRD-260809-01",
  "sourceType": "WORKSHOP", "sourceCode": "WS-01",
  "productionDate": "2026-08-09", "expiryDate": null,
  "status": "ACTIVE", "createdAt": "..."
}
```

## 四、端点详述

### GET /api/materials/{materialId}/batches
- 参数：`status`；默认全量（pageSize=0）。
- 响应 200：`{items,total,page,pageSize}`。错误：MATERIAL_NOT_FOUND（404）。

### GET /api/batches/{id}
- 响应 200：BatchItem。错误：BATCH_NOT_FOUND（404）。

## 五、校验与业务规则

- batchNo：全局唯一、由编号服务生成（格式 B{yyyyMMdd}-{seq}，见通用规范 2.9）。
- sourceType ∈ SUPPLIER / WORKSHOP（与 sourceCode 成对，标签 rt/rc 查名称留档）。
- productionDate / expiryDate：yyyy-MM-dd。
- 生产退料复用原批次：扫描批次标签（t=B）识别原内部批次，不新建。

## 六、错误码

BATCH_NOT_FOUND、MATERIAL_NOT_FOUND、UNAUTHORIZED、FORBIDDEN。
