# 批次接口契约（已锁定 v0.7）

> 状态：**已锁定 v0.7（2026-08-11，用户确认 Q-01 裁决）**。第 3 批已实现查询；批次创建待第 4 批收货流程实现。
> 依据：通用规范 v1.2（编号 2.9）、数据模型 v0.3、标签规范 v0.5。

## 一、批次的生命周期（2026-08-10 确认）
- 批次全部由系统自动建立：收货时生成内部批次号；生产退料扫描原批次标签（t=B）复用原批次；非批控用默认批次（DEFAULT）。
- 用户/前端不手动创建、不删除；本期不提供 POST/DELETE。

## 二、端点
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/materials/{materialId}/batches/search | 某物料批次列表（status/filter/sort） |
| POST | /api/batches/search | 批次列表（keyword/固定参数/filter/sort） |
| GET | /api/batches | 引用选择器快捷搜索（?keyword=&pageSize=） |
| GET | /api/batches/{id} | 批次详情 |

## 四、端点详述
### POST /api/materials/{materialId}/batches/search
- 请求体：`{ status?, filter?, sort?, page?, pageSize? }`；响应 200 分页结构。错误：MATERIAL_NOT_FOUND（404）。
### POST /api/batches/search
- 请求体：`{ keyword?, materialId?, materialCode?, status?, filter?, sort?, page?, pageSize? }`（keyword 匹配 batchNo/sourceBatchNo）。
- 支持 filter DSL；**字段白名单**：materialId、materialCode、batchNo、sourceBatchNo、sourceType、sourceCode、productionDate、expiryDate、status、createdAt。
- **排序白名单**：batchNo、materialCode、status、createdAt；**默认 createdAt DESC（最新在前）**（服务端追加 id DESC 兜底，通用规范 2.10 v2.1）。
- 用途：批次浏览页；batchId: ref(batches) 选择器（通用规范 2.10/1.7）。

### GET /api/batches/{id}

- 响应 200：BatchItem。错误：BATCH_NOT_FOUND（404）。

## 五、校验与业务规则
- **batchNo 格式**：YYMMDD+3 位序号（如 260810001），按"物料+天"重置，编号服务生成（通用规范 2.9）。
- **唯一约束**：(materialId, batchNo) —— 不同物料可同号（永远与物料一起展示/扫码，无歧义）。
- sourceType ∈ SUPPLIER / WORKSHOP（与 sourceCode 成对）。
- 生产退料复用原批次：扫描 t=B 识别原内部批次，不新建。

## 六、错误码
BATCH_NOT_FOUND、MATERIAL_NOT_FOUND、NUMBER_EXHAUSTED（500，编号耗尽）、UNAUTHORIZED、FORBIDDEN。
