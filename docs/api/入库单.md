# 入库单接口契约（第 4 批修订草案 v0.4）

> 状态：**第 4 批修订草案 v0.4（2026-08-19）**。基于已锁定 v0.3 对齐标准 search 端点和 Web 详情字段；待双向评审后重新锁定。
> 依据：通用规范 v2.1、数据模型修订草案 v0.5、ADR-003。

## 一、生命周期与规则
- 创建即 CONFIRMED；无 DRAFT；不提供行修改（改数量=作废重建）。
- 作废：CONFIRMED/RECEIVING 可作废，留痕；作废后不可收货。
- 数量一致性策略由类型决定：PO=STRICT；PR/OT=LENIENT。
- **唯一码**：创建接口不收 uniqueCodes——由打印端点（POST /api/print/unique-labels）按行生成并登记（打印契约 v0.2）。
- **lineNo**：后端分配（同一 order 内 1..N 自增），前端不传。
- **RECEIVED 推进（方案 A，同事务）**：收货提交事务内检查所有行 SUM(actualQty) >= expectedQty（严格=每行收齐；宽松=已覆盖）→ 满足即推进；不采用异步任务。

## 二、状态机
```
创建 ──► CONFIRMED ──► RECEIVING ──► RECEIVED（终态，同事务推进）
              │            │
              └──► VOIDED ─┘（作废留痕）
```
部分收货：一张入库单可被多张收货单分批引用；严格行一次收齐、不同行可分次；宽松行可拆、diff 累计。

## 三、端点
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/inbound-orders | 新建入库单（幂等） |
| POST | /api/inbound-orders/search | 列表（分页+筛选+filter/sort） |
| GET | /api/inbound-orders/{id} | 详情（含行） |
| POST | /api/inbound-orders/{id}/void | 作废（留痕） |

## 四、DTO
```json
{ "id": "uuid", "orderNo": "PO-20260810-0001", "type": "PO",
  "warehouseId": "uuid", "warehouseCode": "WH-01",
  "sourceType": "SUPPLIER", "sourceCode": "SUP-001",
  "status": "CONFIRMED",
  "lines": [ { "id": "uuid", "lineNo": 1, "materialId": "uuid", "materialCode": "MAT-001", "materialName": "螺母 M6",
    "expectedQty": "200.0000", "receivedQty": "0.0000", "remainingQty": "200.0000", "uniqueCodes": [] } ],
  "createdAt": "...", "createdBy": "管理员",
  "voidedAt": null, "voidedBy": null, "voidReason": null
}
```
> 行的唯一码清单（UNRECEIVED/RECEIVED）由打印端点登记后，在详情接口 lines[].uniqueCodes 返回（只读展示）。
> `receivedQty` 为该行全部有效收货行 actualQty 之和；`remainingQty=max(expectedQty-receivedQty, 0)`，宽松超收时保持 0。

## 五、端点详述
### POST /api/inbound-orders
- 请求：{ type, warehouseId, sourceType?, sourceCode?, lines: [{ materialId, expectedQty }] }（不收 uniqueCodes）。
- 响应 201。错误：VALIDATION_ERROR、MATERIAL_NOT_FOUND、WAREHOUSE_NOT_FOUND、ORDER_NUMBER_DUPLICATED、NUMBER_EXHAUSTED、UNAUTHORIZED/FORBIDDEN。
### POST /api/inbound-orders/search
- 请求：`{ type?, warehouseId?, status?, orderNo?, filter?, sort?, page?, pageSize? }`。
- 支持 filter DSL；**字段白名单**：orderNo、type、warehouseId、sourceType、sourceCode、status、createdAt、updatedAt。
- **排序白名单**：orderNo、type、status、createdAt；默认 createdAt desc。
### GET /api/inbound-orders/{id}
- 响应 200：InboundOrder（含行与唯一码清单）。错误：ORDER_NOT_FOUND（404）。
### POST /api/inbound-orders/{id}/void
- 请求：{ reason }。响应 200：status=VOIDED。错误：ORDER_NOT_FOUND、ORDER_STATUS_INVALID。

## 六、错误码
VALIDATION_ERROR、MATERIAL_NOT_FOUND、WAREHOUSE_NOT_FOUND、ORDER_NUMBER_DUPLICATED、ORDER_NOT_FOUND、ORDER_STATUS_INVALID、ORDER_VOIDED、NUMBER_EXHAUSTED、UNAUTHORIZED、FORBIDDEN。
