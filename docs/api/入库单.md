# 入库单接口契约（草案 v0.1，C-03）

> 状态：**草案 v0.1（2026-08-10）**。依据：通用规范 v1.3、数据模型 v0.3、ADR-003。
> 界面词：入库单（采购入库单/生产入库单/其他入库单）；ty=入库类型。

## 一、生命周期与规则（2026-08-10 确认）

- **创建即 CONFIRMED**（可直接被收货引用），不提供 DRAFT 阶段；不提供行修改（改数量=作废重建，ADR 决议）。
- **作废**：CONFIRMED/RECEIVING 可作废，需留痕（谁/何时/原因）；作废后不可再被收货引用。
- **数量一致性策略由类型决定**：PO=STRICT（严格，收货必须一致）；PR/OT=LENIENT（宽松，按实收）。策略不暴露为可编辑字段。
- 唯一码清单挂在行上（仅 labelType=UNIQUE 的物料允许）；同单内不重复。

## 二、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/inbound-orders | 新建入库单（幂等） |
| GET | /api/inbound-orders | 列表（分页+筛选） |
| GET | /api/inbound-orders/{id} | 详情（含行） |
| POST | /api/inbound-orders/{id}/void | 作废（留痕） |

## 四、端点详述

### POST /api/inbound-orders
- 请求：`{ type, warehouseId, sourceType?, sourceCode?, lines: [{ materialId, expectedQty, uniqueCodes? }] }`
- 响应 201：InboundOrder。错误：VALIDATION_ERROR（400）、MATERIAL_NOT_FOUND（404）、WAREHOUSE_NOT_FOUND（404）、ORDER_NUMBER_DUPLICATED（409）、NUMBER_EXHAUSTED（500）、UNAUTHORIZED/FORBIDDEN。
- 规则：type ∈ PO/PR/OT；lines 至少 1 行；expectedQty > 0；uniqueCodes 仅允许物料 labelType=UNIQUE 时提供且同单不重复。

### GET /api/inbound-orders
- 筛选：`type`、`warehouseId`、`status`、`orderNo`（模糊）、`page`、`pageSize`。
- 响应 200：`{items,total,page,pageSize}`。

### GET /api/inbound-orders/{id}
- 响应 200：InboundOrder（含行与唯一码清单）。错误：ORDER_NOT_FOUND（404）。

### POST /api/inbound-orders/{id}/void
- 请求：`{ reason }`（必填）。
- 响应 200：InboundOrder（status=VOIDED）。错误：ORDER_NOT_FOUND（404）、ORDER_STATUS_INVALID（409，已 VOIDED/RECEIVED 不可作废）。

## 五、错误码
VALIDATION_ERROR、MATERIAL_NOT_FOUND、WAREHOUSE_NOT_FOUND、ORDER_NUMBER_DUPLICATED、ORDER_NOT_FOUND、ORDER_STATUS_INVALID、ORDER_VOIDED、NUMBER_EXHAUSTED、UNAUTHORIZED、FORBIDDEN。
