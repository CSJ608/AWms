# 附件接口契约（已锁定 v0.2）

> 状态：**已锁定 v0.2**。第 2 批 C-05 锁定；待第 4 批拍照场景实现。
> 定位：拍照（收货/质检/异常）与照片查看的通用能力；**先上传拿 uploadId，业务提交时关联**（收货提交带 photos、质检带 photoIds）。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/attachments | 上传（multipart） |
| GET | /api/attachments/{id} | 下载/查看（inline） |
| GET | /api/attachments/{id}/thumbnail | 缩略图（列表用） |
| GET | /api/attachments | 列表（按 bizType/bizId/上传人/时间） |
| DELETE | /api/attachments/{id} | 删除（未关联可删；已关联保护） |

## 二、DTO

```json
{
  "id": "uuid",
  "fileName": "IMG_001.jpg",
  "mimeType": "image/jpeg",
  "size": 204800,
  "bizType": "RECEIPT", "bizId": "uuid",   // 业务提交回填前为 null
  "uploadedBy": "uuid", "uploadedByName": "王仓管",
  "uploadedAt": "2026-08-10T00:00:00Z",
  "url": "/api/attachments/{id}",
  "thumbnailUrl": "/api/attachments/{id}/thumbnail"
}
```

## 三、端点详述

### POST /api/attachments
- multipart：`file`（必填）、`bizType?`（可选预填）。
- 限制：单张 ≤10MB；类型 jpg/png/webp（ATTACHMENT_TYPE_INVALID）；每收货单 ≤3 张（业务接口校验，非本接口）。
- 响应 201：AttachmentItem（id/url）。错误：ATTACHMENT_TOO_LARGE（413）、ATTACHMENT_TYPE_INVALID（400）、VALIDATION_ERROR。

### GET /api/attachments/{id}
- 响应 200：文件流（inline，Content-Type 按 mimeType）。错误：ATTACHMENT_NOT_FOUND（404）。

### GET /api/attachments/{id}/thumbnail
- 响应 200：缩略图（列表页用，后端生成缓存）。错误：ATTACHMENT_NOT_FOUND（404）。

### GET /api/attachments
- 筛选：`bizType`、`bizId`、`uploadedBy`、`dateFrom`、`dateTo`、`page`、`pageSize`。
- 响应 200：分页结构（不含文件流，含 url/thumbnailUrl）。
- 用途：收货单照片查看页（bizType=RECEIPT&bizId=xxx）。

### DELETE /api/attachments/{id}
- 响应 204。错误：ATTACHMENT_NOT_FOUND（404）、ATTACHMENT_IN_USE（409，已关联业务禁止删除）。

## 四、业务规则

1. **先上传后关联**：上传返回 id；收货提交（photos）与质检（photoIds）把 id 带上，后端回填 bizType/bizId。
2. 存储：本地文件系统 + 元数据表（ADR-004 v0.3）；根路径配置 Storage:AttachmentsRoot；子目录按 bizType/yyyy/MM 分桶；文件名 {uuid}.{ext}（防路径穿越）；物理删除与元数据删除解耦（异步清理）。
3. 权限：上传/删除需对应业务的操作权限；查看按业务查看权限。
4. 批量导出（未来"导出查看"愿景）：后置（先支持单张查看/缩略图）。

## 五、错误码

ATTACHMENT_TOO_LARGE、ATTACHMENT_TYPE_INVALID、ATTACHMENT_NOT_FOUND、ATTACHMENT_IN_USE、VALIDATION_ERROR、UNAUTHORIZED、FORBIDDEN。
