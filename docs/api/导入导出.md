# 导入导出接口契约（草案 v0.1，C-03）

> 状态：**草案 v0.1（2026-08-10）**。依据：通用规范 v1.7（filter/sort/字段元数据）、ADR-004（平台能力，参考 TemplateFrame 思路自研）、数据模型 v0.4。
> 定位：**平台能力**（moduleCode 注册），本期启用模块=物料（仓库/库位/来源随主数据批次扩展）。
> 已确认：仅"新增"（重复编码报错）；**全部校验通过才可执行**；标准模板（数据 Sheet + 说明 Sheet + 字典 Sheet）；内置固定模板（配置化后置）。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/import-export/templates/{moduleCode} | 下载导入模板 |
| POST | /api/import-export/precheck | 上传文件 → 预校验（**不落库**） |
| POST | /api/import-export/execute | 确认执行导入（全部通过才可） |
| POST | /api/import-export/export | 创建导出任务（异步） |
| GET | /api/import-export/tasks/{id} | 任务状态/结果 |
| GET | /api/import-export/tasks/{id}/fail-report | 失败明细文件下载 |
| GET | /api/import-export/tasks/{id}/file | 导出结果文件下载 |

## 三、端点详述

### GET /api/import-export/templates/{moduleCode}
- 响应 200：模板文件（xlsx，含 数据/说明/字典 三个 Sheet）。
- 错误：IMPORT_TASK_NOT_FOUND（不适用）→ 用 NOT_FOUND（404，模板不存在）。

### POST /api/import-export/precheck
- multipart：`file`、`moduleCode`。
- 行为：解析 → **只校验不落库**；创建/返回 ImportTask（status=PRECHECKED；failCount>0 → canExecute=false）。
- 校验分层（本期物料）：文件级（类型/表头）→ 字段级（必填/长度/枚举 labelType/UOM）→ 引用级（单位等）→ 行级业务（编码唯一：文件内重复 + 与库中重复）。
- 响应 200：ImportTask（含 failures 明细列表或 failReportUrl）。错误：IMPORT_PARSE_ERROR（422）、VALIDATION_ERROR。

### POST /api/import-export/execute
- 请求：`{ taskId }`。
- 规则：**canExecute=true 才允许**（全部校验通过）；执行后 status=DONE/FAILED，返回结果（成功数）。
- 错误：IMPORT_TASK_NOT_FOUND（404）、IMPORT_VALIDATION_FAILED（422，仍有失败项）。

### POST /api/import-export/export
- 请求：`{ moduleCode, filter?, sort?, pageSize? }`（filter/sort 遵循通用规范 2.10；pageSize=0 全量）。
- 行为：创建导出任务（异步），status=PROCESSING → DONE；文件与导入模板同结构（含字典翻译、日期格式化）。
- 响应 201：ImportTask（direction=EXPORT）。错误：EXPORT_FAILED（500）。

### GET /api/import-export/tasks/{id}
- 响应 200：ImportTask。错误：IMPORT_TASK_NOT_FOUND（404）。

### GET /api/import-export/tasks/{id}/fail-report
- 响应 200：失败明细文件（xlsx/csv）。错误：IMPORT_TASK_NOT_FOUND（404）。

### GET /api/import-export/tasks/{id}/file
- 响应 200：导出结果文件。错误：IMPORT_TASK_NOT_FOUND（404）。

## 四、业务规则

1. **平台能力**：moduleCode 注册（本期 materials）；字段元数据驱动模板与校验（通用规范 2.10 FieldMeta 复用）。
2. **两阶段导入**：预校验不落库 → 全部通过才执行；失败明细精确到"行号/列/原始值/原因/建议"。
3. **仅新增**：重复编码（文件内/库中）报错，不做覆盖更新（本期）。
4. **导出留审计**：谁导出了什么（任务表留痕）；异步任务 + 文件下载。
5. **编号**：任务号走编号服务（IMP-…，通用规范 2.9）。
6. **权限**：导入/导出按钮按角色操作权限；导出按数据权限（本期全量可见，数据权限后置）。
7. 参考 TemplateFrame（契约+版式+填充）思路，**自研实现**，不照搬代码（参考说明见 docs/references/参考-TemplateFrame与Wms4-导入导出打印.md）。
