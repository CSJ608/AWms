## 二、错误码（hex 区间预占）

| 区间 | 模块 |
|---|---|
| 0x00000–0x00FFF | 通用 |
| 0x01000–0x01FFF | 主数据 |
| 0x02000–0x02FFF | 入库链 |
| 0x03000–0x03FFF | 库存 |
| 0x04000–0x04FFF | 系统/权限 |
| 0x05000–0x05FFF | 导入导出/附件/打印 |

> 契约层前端只消费字符串 code；hex 为内部编号（日志/工单/对接）。

## 三、前端约定（v0.3）

- **不维护错误文案映射**：默认直接展示后端 message。
- **code 行为分支（含静默动作）**：
  - UNAUTHORIZED：静默刷新 token → 重放原请求；刷新失败跳登录；
  - FORBIDDEN：提示无权限；
  - QTY_MISMATCH_STRICT：引导"作废重建"；
  - IMPORT_VALIDATION_FAILED：展示 data 失败明细；
  - UNIQUE_CODE_ALREADY_RECEIVED：静默刷新待收唯一码清单 + 防重提示；
  - ORDER_VOIDED / VERSION_CONFLICT：静默刷新列表/单据，提示重新操作；
  - NETWORK_ERROR / UNKNOWN_ERROR：本地兜底。
- 后端 message 未知语言回退中文；必须完整（不得只返回 code）。
