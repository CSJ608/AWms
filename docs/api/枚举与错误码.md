# 枚举与错误码（已定稿 v1.2）

> 状态：**已定稿 v1.3（2026-08-10，用户确认）**。v1.2：入库单状态移除 DRAFT；新增收货行状态与错误码 RECEIPT_LINE_NOT_FOUND、QUALITY_CHECK_NOT_FOUND。

## 一、枚举

### 1. 通用状态
| 枚举 | 值 | 界面词 |
|---|---|---|
| 库存主体状态 | PENDING_INSPECTION / AVAILABLE / FROZEN | 待检 / 可用 / 冻结（预留） |
| 物料状态 | ENABLED / DISABLED | 启用 / 停用 |
| 库位类型 | STAGING / DEFAULT | 暂存 / 默认 |
| 标签类型 | NONE / SKU / UNIQUE | 无 / SKU码 / 唯一码 |
| 仓库管理方式（预留） | MANUAL / AGV | 人工 / AGV |
| 库位可达性（预留） | MANUAL_ONLY / AGV / UNIVERSAL | 仅人工 / AGV / 通用 |

### 2. 单位码 UOM
CT / PC / BOX / KG / G / L / M（个/件/箱/千克/克/升/米）

### 3. 入库链
| 枚举 | 值 |
|---|---|
| 入库单类型 ty | PO / PR / OT |
| 入库单状态 | **CONFIRMED / RECEIVING / RECEIVED / VOIDED**（创建即 CONFIRMED，无 DRAFT） |
| 收货单状态 | RECEIVING / CHECKING / PUTAWAY / DONE |
| **收货行状态** | **RECEIVED / CHECKED / EXCEPTION / PUTAWAY_DONE** |
| 质检结果 | PASS / EXCEPTION |
| 质检处理动作 | PASS / REJECT |
| 唯一码状态 | UNRECEIVED / RECEIVED |
| 数量一致性策略 | STRICT / LENIENT（PO=STRICT，PR/OT=LENIENT） |

### 4. 系统
| 枚举 | 值 |
|---|---|
| 来源类型 rt | SUPPLIER / WORKSHOP |
| 用户状态 | ACTIVE / DISABLED |
| 权限类别 | ROUTE / MENU / ACTION |
| 界面端 surface | WEB / PDA |
| 导入任务状态 | PRECHECKING / PRECHECKED / EXECUTING / DONE / FAILED |
| 附件业务类型 | RECEIPT / QUALITY_CHECK / EXCEPTION |

## 二、错误码（hex 区间预占）
区间：通用 0x00 / 主数据 0x01 / 入库链 0x02 / 库存 0x03 / 系统 0x04 / 支撑 0x05。

### 通用
VALIDATION_ERROR 0x000001 400 / UNAUTHORIZED 0x000002 401 / FORBIDDEN 0x000003 403 / NOT_FOUND 0x000004 404 / CONFLICT 0x000005 409 / INTERNAL_ERROR 0x000006 500 / NUMBER_EXHAUSTED 0x000007 500 / NETWORK_ERROR / UNKNOWN_ERROR（前端）。

### 主数据（0x01xxx）
MATERIAL_CODE_DUPLICATED 0x010101 / MATERIAL_NOT_FOUND 0x010102 / MATERIAL_IN_USE 0x010103
WAREHOUSE_CODE_DUPLICATED 0x010201 / WAREHOUSE_NOT_FOUND 0x010202 / WAREHOUSE_IN_USE 0x010203
LOCATION_CODE_DUPLICATED 0x010301 / LOCATION_NOT_FOUND 0x010302 / LOCATION_TYPE_INVALID 0x010303 / LOCATION_IN_USE 0x010304
SOURCE_CODE_DUPLICATED 0x010401 / SOURCE_NOT_FOUND 0x010402 / SOURCE_IN_USE 0x010403
BATCH_NOT_FOUND 0x010501 / BATCH_NO_DUPLICATED 0x010502

### 入库链（0x02xxx）
ORDER_NOT_FOUND 0x020101 / ORDER_NUMBER_DUPLICATED 0x020102 / ORDER_STATUS_INVALID 0x020103 / ORDER_VOIDED 0x020104 / ORDER_LINE_MISMATCH 0x020105
RECEIPT_NOT_FOUND 0x020201 / RECEIPT_STATUS_INVALID 0x020202 / QTY_MISMATCH_STRICT 0x020203 / UNIQUE_CODE_NOT_IN_ORDER 0x020204 / UNIQUE_CODE_ALREADY_RECEIVED 0x020205 / BATCH_REQUIRED 0x020206
QC_STATUS_INVALID 0x020301 / QUALITY_CHECK_NOT_FOUND 0x020302
PUTAWAY_LOCATION_INVALID 0x020401
RECEIPT_LINE_NOT_FOUND 0x020501（v1.2 新增）

### 库存（0x03xxx）
SUBJECT_NOT_FOUND 0x030101 / PHYSICAL_INVENTORY_NOT_FOUND 0x030102 / INSUFFICIENT_STOCK 0x030103 / LEDGER_LINE_NOT_FOUND 0x030104 / VERSION_CONFLICT 0x030105

### 系统/权限（0x04xxx）

| code | hex | HTTP | 说明 |
|---|---|---|---|
| LOGIN_FAILED | 0x040101 | 401 | 用户名或密码错误 |
| USER_DISABLED | 0x040102 | 401 | 账号停用 |
| USER_NOT_FOUND | 0x040103 | 404 | 用户不存在 |
| USERNAME_DUPLICATED | 0x040104 | 409 | 用户名重复 |
| ROLE_NOT_FOUND | 0x040105 | 404 | 角色不存在 |
| ROLE_CODE_DUPLICATED | 0x040106 | 409 | 角色编码重复 |
| ROLE_IN_USE | 0x040107 | 409 | 角色被用户引用，禁止删除 |

### 支撑（0x05xxx）
IMPORT_PARSE_ERROR 0x050101 / IMPORT_VALIDATION_FAILED 0x050102 / IMPORT_TASK_NOT_FOUND 0x050103 / EXPORT_FAILED 0x050104
ATTACHMENT_TOO_LARGE 0x050201 / ATTACHMENT_NOT_FOUND 0x050202 / PRINT_TEMPLATE_NOT_FOUND 0x050301

## 三、前端约定
- 默认展示后端 message；code=判断"是否需要做特别的事"的钥匙（静默或提示）。
- 收货相关行为分支：QTY_MISMATCH_STRICT（引导作废重建）、UNIQUE_CODE_ALREADY_RECEIVED（静默刷新清单+防重提示）、ORDER_VOIDED / VERSION_CONFLICT（静默刷新）。
