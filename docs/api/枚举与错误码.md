# 枚举与错误码（草案 v0.1，C-04）

> 状态：**草案（2026-08-10，待评审）**。随各模块契约扩展；此处为全集。

## 一、枚举

### 1. 通用状态

| 枚举 | 值 | 界面词 |
|---|---|---|
| 库存主体状态 | PENDING_INSPECTION / AVAILABLE / FROZEN | 待检 / 可用 / 冻结（FROZEN 本期预留） |
| 物料状态 | ENABLED / DISABLED | 启用 / 停用 |
| 库位类型 | STAGING / DEFAULT | 暂存 / 默认 |
| 标签类型 | NONE / SKU / UNIQUE | 无 / SKU码 / 唯一码 |
| 仓库管理方式（预留） | MANUAL / AGV | 人工 / AGV |
| 库位可达性（预留） | MANUAL_ONLY / AGV / UNIVERSAL | 仅人工 / AGV / 通用 |

### 2. 入库链

| 枚举 | 值 |
|---|---|
| 入库单类型 ty | PO / PR / OT（采购入库 / 生产入库 / 其他入库） |
| 入库单状态 | DRAFT / CONFIRMED / RECEIVING / RECEIVED / VOIDED |
| 收货单状态 | RECEIVING / CHECKING / PUTAWAY / DONE |
| 质检结果 | PASS / EXCEPTION |
| 唯一码状态 | UNRECEIVED / RECEIVED |
| 数量一致性策略 | STRICT / LENIENT（按 ty：PO=STRICT，PR/OT=LENIENT） |

### 3. 系统

| 枚举 | 值 |
|---|---|
| 来源类型 rt | SUPPLIER / WORKSHOP（供应商 / 生产车间） |
| 用户状态 | ACTIVE / DISABLED |
| 权限类别 | ROUTE / MENU / ACTION |
| 界面端 surface | WEB / PDA |
| 导入任务状态 | PRECHECKING / PRECHECKED / EXECUTING / DONE / FAILED |
| 附件业务类型 | RECEIPT / QUALITY_CHECK / EXCEPTION |

## 二、错误码

### 通用

| code | HTTP | 说明 |
|---|---|---|
| VALIDATION_ERROR | 400 | 参数校验失败（data 含字段明细） |
| UNAUTHORIZED | 401 | 未登录/会话失效 |
| FORBIDDEN | 403 | 无权限 |
| NOT_FOUND | 404 | 资源不存在 |
| CONFLICT | 409 | 状态冲突/重复操作 |
| INTERNAL_ERROR | 500 | 内部错误 |
| NETWORK_ERROR | -（前端） | 网络失败 |
| UNKNOWN_ERROR | -（前端） | 未知错误码兜底 |

### 主数据

| code | HTTP | 说明 |
|---|---|---|
| MATERIAL_CODE_DUPLICATED | 409 | 物料编码重复 |
| MATERIAL_NOT_FOUND | 404 | 物料不存在 |
| MATERIAL_IN_USE | 409 | 物料被引用，禁止删除 |
| WAREHOUSE_CODE_DUPLICATED | 409 | 仓库编码重复 |
| WAREHOUSE_NOT_FOUND | 404 | 仓库不存在 |
| WAREHOUSE_IN_USE | 409 | 仓库被引用，禁止删除 |
| LOCATION_CODE_DUPLICATED | 409 | 库位编码重复（仓内） |
| LOCATION_NOT_FOUND | 404 | 库位不存在 |
| LOCATION_TYPE_INVALID | 400 | 库位类型非法 |
| LOCATION_IN_USE | 409 | 库位被引用/有货，禁止删除 |
| SOURCE_CODE_DUPLICATED | 409 | 来源代码重复 |
| SOURCE_NOT_FOUND | 404 | 来源不存在 |
| BATCH_NOT_FOUND | 404 | 批次不存在 |
| BATCH_NO_DUPLICATED | 409 | 批次号重复 |

### 入库链

| code | HTTP | 说明 |
|---|---|---|
| ORDER_NOT_FOUND | 404 | 入库单不存在 |
| ORDER_NUMBER_DUPLICATED | 409 | 单据号重复 |
| ORDER_STATUS_INVALID | 409 | 入库单状态不允许该操作 |
| ORDER_VOIDED | 409 | 单据已作废 |
| ORDER_LINE_MISMATCH | 400 | 扫描物料不在单据行 |
| RECEIPT_NOT_FOUND | 404 | 收货单不存在 |
| RECEIPT_STATUS_INVALID | 409 | 收货单状态不允许该操作 |
| QTY_MISMATCH_STRICT | 422 | 严格策略：实收≠应到，需作废重建 |
| UNIQUE_CODE_NOT_IN_ORDER | 400 | 唯一码不在本单据清单 |
| UNIQUE_CODE_ALREADY_RECEIVED | 409 | 唯一码已收过（防重） |
| BATCH_REQUIRED | 400 | 批控物料必须选择批次 |
| QC_STATUS_INVALID | 409 | 质检状态不允许 |
| PUTAWAY_LOCATION_INVALID | 400 | 上架库位类型/容量不匹配 |

### 库存

| code | HTTP | 说明 |
|---|---|---|
| SUBJECT_NOT_FOUND | 404 | 库存主体不存在 |
| PHYSICAL_INVENTORY_NOT_FOUND | 404 | 物理库存不存在 |
| INSUFFICIENT_STOCK | 409 | 库存不足 |
| LEDGER_LINE_NOT_FOUND | 404 | 流水不存在 |
| VERSION_CONFLICT | 409 | 并发版本冲突（乐观锁） |

### 导入导出/附件/打印

| code | HTTP | 说明 |
|---|---|---|
| IMPORT_PARSE_ERROR | 422 | 文件解析失败 |
| IMPORT_VALIDATION_FAILED | 422 | 预校验失败（data 含明细，不落库） |
| IMPORT_TASK_NOT_FOUND | 404 | 导入任务不存在 |
| EXPORT_FAILED | 500 | 导出失败 |
| ATTACHMENT_TOO_LARGE | 413 | 附件超限 |
| ATTACHMENT_NOT_FOUND | 404 | 附件不存在 |
| PRINT_TEMPLATE_NOT_FOUND | 404 | 打印模板不存在 |

## 三、前端 i18n 约定

- key 结构：`ERROR.<CODE>`（如 `ERROR.MATERIAL_CODE_DUPLICATED`），zh/en 键结构一致。
- 前端 labels 层只判 code；未知码回退 `UNKNOWN_ERROR`。
