# 仓库库位接口契约（草案 v0.1）

> 状态：**草案 v0.1（2026-08-10）**。依据：通用规范 v1.0、数据模型 v0.1。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/warehouses | 列表（默认全量） |
| POST | /api/warehouses | 新建仓库 |
| PUT | /api/warehouses/{id} | 编辑（code 只读） |
| DELETE | /api/warehouses/{id} | 删除（引用保护） |
| GET | /api/warehouses/{warehouseId}/locations | 库位列表（默认全量，可按 type 筛） |
| POST | /api/warehouses/{warehouseId}/locations | 新建库位 |
| PUT | /api/locations/{id} | 编辑库位（code 只读） |
| DELETE | /api/locations/{id} | 删除库位（引用保护） |

## 三、端点详述

### GET /api/warehouses
- 参数：`status`、`page`、`pageSize`（默认 0 全量）。
- 响应 200：分页或全量 `{items,total,page,pageSize}`。

### POST /api/warehouses
- 请求：`{ code, name, status?, mgmtMode? }`（mgmtMode 本期默认 MANUAL，预留不可改）。
- 响应 201。错误：WAREHOUSE_CODE_DUPLICATED（409）、VALIDATION_ERROR。

### PUT /api/warehouses/{id}
- 请求：`{ name, status }`。响应 200。错误：WAREHOUSE_NOT_FOUND（404）。

### DELETE /api/warehouses/{id}
- 响应 204。错误：WAREHOUSE_IN_USE（409，有库位/被引用禁止删除）。

### GET /api/warehouses/{warehouseId}/locations
- 参数：`type`（STAGING/DEFAULT）、`status`、`page`、`pageSize`（默认全量）。
- 响应 200：分页结构。

### POST /api/warehouses/{warehouseId}/locations
- 请求：`{ code, type, status? }`。
- 响应 201。错误：LOCATION_CODE_DUPLICATED（409，仓内唯一）、LOCATION_TYPE_INVALID（400）、WAREHOUSE_NOT_FOUND（404）。

### PUT /api/locations/{id}
- 请求：`{ type, status }`。响应 200。错误：LOCATION_NOT_FOUND（404）、LOCATION_TYPE_INVALID。

### DELETE /api/locations/{id}
- 响应 204。错误：LOCATION_IN_USE（409，有货/被引用禁止删除）。

## 四、校验与业务规则

- warehouse.code：1..64、唯一、不可改。
- location.code：1..64、**仓内唯一**、不可改。
- type ∈ STAGING / DEFAULT（本期）。
- reachability：预留字段，本期返回默认 UNIVERSAL，不启用校验（ADR-002）。
- 删除保护：仓库有库位/被单据引用禁止删除；库位有物理库存/被引用禁止删除。

## 五、错误码

WAREHOUSE_CODE_DUPLICATED、WAREHOUSE_NOT_FOUND、WAREHOUSE_IN_USE、LOCATION_CODE_DUPLICATED、LOCATION_NOT_FOUND、LOCATION_TYPE_INVALID、LOCATION_IN_USE、VALIDATION_ERROR、UNAUTHORIZED、FORBIDDEN。
