# 仓库库位接口契约（草案 v0.2）

> 状态：**草案 v0.2（2026-08-10）**。v0.2：Warehouse/Location 新增 searchCode；列表支持 keyword（通用规范 2.10/1.7）。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/warehouses/search | 仓库列表（keyword/固定参数/filter/sort，通用规范 2.10） |
| GET | /api/warehouses | 引用选择器快捷搜索（?keyword=&pageSize=） |
| POST | /api/warehouses | 新建仓库 |
| PUT | /api/warehouses/{id} | 编辑（code 只读） |
| DELETE | /api/warehouses/{id} | 删除（引用保护） |
| POST | /api/warehouses/{warehouseId}/locations/search | 库位列表（keyword/固定参数/filter/sort） |
| GET | /api/warehouses/{warehouseId}/locations | 引用选择器快捷搜索（?keyword=&pageSize=） |
| POST | /api/warehouses/{warehouseId}/locations | 新建库位 |
| PUT | /api/locations/{id} | 编辑库位（code 只读） |
| DELETE | /api/locations/{id} | 删除库位（引用保护） |

## 三、端点详述

### POST /api/warehouses/search
- 请求体：`{ keyword?, status?, filter?, sort?, page?, pageSize? }`（keyword 匹配 code/name/searchCode）。
- 支持 filter DSL；**字段白名单**：code、name、searchCode、status、mgmtMode、createdAt。
- **排序白名单**：code、name、status、createdAt；默认 code asc（服务端追加 id 兜底，通用规范 2.10 v2.1）。

### POST /api/warehouses
- 请求：`{ code, name, searchCode?, status?, mgmtMode? }`。响应 201。错误：WAREHOUSE_CODE_DUPLICATED（409）、VALIDATION_ERROR。

### PUT /api/warehouses/{id}
- 请求：`{ name, searchCode?, status }`。响应 200。错误：WAREHOUSE_NOT_FOUND（404）。

### DELETE /api/warehouses/{id}
- 响应 204。错误：WAREHOUSE_IN_USE（409）。

### POST /api/warehouses/{warehouseId}/locations/search
- 请求体：`{ keyword?, type?, status?, filter?, sort?, page?, pageSize? }`（keyword 匹配 code/searchCode）。
- 支持 filter DSL；**字段白名单**：code、searchCode、type、status、reachability、createdAt。
- **排序白名单**：code、type、status、createdAt；默认 code asc（服务端追加 id 兜底，通用规范 2.10 v2.1）。

### POST /api/warehouses/{warehouseId}/locations
- 请求：`{ code, searchCode?, type, status? }`。响应 201。错误：LOCATION_CODE_DUPLICATED（409）、LOCATION_TYPE_INVALID（400）、WAREHOUSE_NOT_FOUND（404）。

### PUT /api/locations/{id}
- 请求：`{ type, searchCode?, status }`。响应 200。错误：LOCATION_NOT_FOUND（404）、LOCATION_TYPE_INVALID。

### DELETE /api/locations/{id}
- 响应 204。错误：LOCATION_IN_USE（409）。

## 四、校验与业务规则

- warehouse.code：1..64、唯一、不可改；name 必填；searchCode 可选 1..32。
- location.code：1..64、**仓内唯一**、不可改；searchCode 可选 1..32。
- type ∈ STAGING/DEFAULT；reachability 预留默认 UNIVERSAL。
- 删除保护：仓库有库位/被引用禁止删除；库位有货/被引用禁止删除。

## 五、错误码

WAREHOUSE_CODE_DUPLICATED、WAREHOUSE_NOT_FOUND、WAREHOUSE_IN_USE、LOCATION_CODE_DUPLICATED、LOCATION_NOT_FOUND、LOCATION_TYPE_INVALID、LOCATION_IN_USE、VALIDATION_ERROR、UNAUTHORIZED、FORBIDDEN。
