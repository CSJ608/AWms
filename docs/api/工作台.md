# 工作台接口契约（草案 v0.1，C-03）

> 状态：**草案 v0.1（2026-08-10）**。依据：界面规格《首页-Web工作台》v1.0、通用规范 v1.7、收货契约 v0.2、库存契约 v0.3。
> 角色：仓管/主管（主要）、作业员（浏览）。回答："现在仓库里有什么待办、异常，最近发生了什么"。

## 一、端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/dashboard/summary | 工作台聚合（KPI + 待办 + 最近流水） |

> 快捷操作（新建入库单 / 打印中心 / 照片查看）是前端路由跳转，无数据依赖，不在本契约。

## 三、端点详述

### GET /api/dashboard/summary
- 参数：`warehouseId`（可选，不传=全部仓库）、`todoLimit`（默认 5，最大 20）、`ledgerLimit`（默认 10，最大 50）。
- 响应 200：见 DTO。
- **KPI 口径**（与各契约一致）：
  - pendingInspection = 待质检行数（receiptLine.status=RECEIVED，同 /api/quality-todos total）；
  - pendingPutaway = 待上架行数（同 /api/putaway-todos total）；
  - exceptions = 未处理的质检异常数（qualityCheck.result=EXCEPTION 且未 resolve）；
  - availableSkus = 可用主体数（/api/stocks?status=AVAILABLE total）。
- **待办列表**：三类各返回前 todoLimit 条（同 quality-todos / putaway-todos / exceptions 查询）。
- **recentLedgers**：最新 ledgerLimit 条（同 /api/stock-ledgers 默认排序）。

## 四、业务规则

1. 聚合查询可一次返回，避免首页 5 个请求；各分项与对应列表接口口径一致（前端可点"查看全部"跳到对应页）。
2. 权限：按当前用户角色过滤（无可访问模块则对应区块为空/隐藏）。
3. 本期不做：今日动态时间线、趋势图、轮询（手动刷新 + 进入刷新）。

## 五、错误码

VALIDATION_ERROR、UNAUTHORIZED、FORBIDDEN。
