## 三、端点详述

### POST /api/auth/login
- 请求：`{ username, password }`。响应 200：LoginResponse。
- 错误：LOGIN_FAILED（401）、USER_DISABLED（401）、VALIDATION_ERROR（400）。

### POST /api/auth/refresh
- 请求头 Bearer（过期 token）或 body `{ refreshToken }`（实现细节契约批后端定）。
- 响应 200：`{ token, expiresAt }`。错误：UNAUTHORIZED（401）。

### POST /api/auth/logout
- 响应 204（服务端使 token 失效；实现可无状态）。

### GET /api/auth/me
- 响应 200：LoginResponse 同构（user/permissions/menus）。错误：UNAUTHORIZED（401）。

### GET /api/users
- 固定参数：`keyword`（username/name）、`status`、`page`、`pageSize`。
- filter/sort 白名单：username、name、status、createdAt；默认 username asc。

### POST /api/users
- 请求：`{ username, name, password, status?, roleIds? }`。响应 201：UserItem。
- 错误：USERNAME_DUPLICATED（409）、VALIDATION_ERROR。

### PUT /api/users/{id}
- 请求：`{ name, status }`（username 不可改）。响应 200。错误：USER_NOT_FOUND（404）。

### PUT /api/users/{id}/roles
- 请求：`{ roleIds: [] }`。响应 200：UserItem。

### POST /api/users/{id}/reset-password
- 请求：`{ newPassword }`。响应 204。

### GET /api/roles
- 参数：`keyword`（code/name）、`page`、`pageSize`（默认全量）。
- 响应 200：`RoleItem[]`（本期返回全量数组；page/pageSize 参数预留，后续如需分页再扩展）。

### POST /api/roles
- 请求：`{ code, name, permissionCodes? }`。响应 201。错误：ROLE_CODE_DUPLICATED（409）。

### PUT /api/roles/{id}
- 请求：`{ name, permissionCodes? }`。响应 200。错误：ROLE_NOT_FOUND（404）。

### PUT /api/roles/{id}/permissions
- 请求：`{ permissionCodes: [] }`。响应 200：RoleItem。

### DELETE /api/roles/{id}
- 响应 204。错误：ROLE_NOT_FOUND（404）、ROLE_IN_USE（409，被用户引用）。

### GET /api/permissions
- 响应 200：PermissionItem[]（按 moduleCode/category 排序；来自模块注册表，只读）。

## 四、业务规则

1. **独立账号**：每个作业员一个账号，操作人身份进入流水/审计（"谁"）。
2. **初始角色**：系统管理员（SYSTEM_ADMIN）/ 仓管（SUPERVISOR）/ 作业员（OPERATOR）。
3. **三级权限**：路由（能否进入模块）/ 菜单（是否显示入口）/ 操作（按钮/动作），查看与操作分离。
4. **模块注册表**：菜单（web/pda）与权限点由注册表驱动；新增模块=注册表加一项，框架不动（ADR-001）。
5. **密码**：哈希存储；管理员可重置；无注册/找回（内部系统）。
6. 401 → 前端静默刷新重放；刷新失败 → 跳登录（通用规范 2.7）。
