# 数据模型（草案 v0.4，C-02）

> 状态：**草案 v0.4（2026-08-10）**。v0.4：ReceiptLine 增加 orderLineId（有预建单时必填），消除同物料多行歧义；标签 ol 引用 InboundOrderLine.id。
> 依据：概念设计 v1.0、通用规范 v1.3、标签规范 v0.11。

## 一、建模原则
1. 概念命名保持；表名与契约字段英文；界面词用《术语对照表》。
2. 只建本期功能需要的表；预留概念只留字段位。
3. 流水只追加；物理库存带版本号防并发。
4. 来源单据与收货单分离（逻辑引用，ADR-003）。

## 二、实体清单（分组）
- 系统基础：User / Role / Permission / Module / MenuEntry / UserRole / RolePermission
- 主数据：Material / Warehouse / Location / Source / Batch（系统自动建立）
- 入库链：InboundOrder / InboundOrderLine / UniqueCode / Receipt / ReceiptLine / QualityCheck / PutawayRecord
- 库存账目：StockSubject / PhysicalInventory / StockLedger / TxnGroup
- 支撑：Attachment / PrintLog / ImportTask / ImportTaskDetail / Sequence

## 三、关键实体与字段（概念级）

### 主数据
| 实体 | 关键字段 | 说明 |
|---|---|---|
| Material | code(唯一)、name、batchControlled、labelType、defaultUom、status | — |
| Warehouse | code(唯一)、name、status、mgmtMode(预留) | — |
| Location | warehouseId、code(仓内唯一)、type、status、reachability(预留) | — |
| Source | type、code、name、status | (type,code) 同类型唯一 |
| Batch | batchNo、materialId、sourceBatchNo?、productionDate?、expiryDate?、sourceType?、sourceCode?、status | 唯一(materialId,batchNo)；系统自动建立 |

### 入库链
| 实体 | 关键字段 | 说明 |
|---|---|---|
| InboundOrder | orderNo(唯一)、type、warehouseId、sourceType?、sourceCode?、status、voidedBy/At/Reason | 统一表+类型 |
| InboundOrderLine | orderId、materialId、expectedQty、lineNo、batchId? | 行身份（标签 ol 引用它） |
| UniqueCode | orderLineId、code、status、receivedAt | 扫一个勾一个 |
| Receipt | receiptNo(唯一)、warehouseId、sourceType?、sourceDocNo?、status、operatorId、occurredAt | 逻辑引用 |
| ReceiptLine | receiptId、**orderLineId?（有预建单时必填，逻辑引用 InboundOrderLine.id）**、materialId、batchId(收货生成)、expectedQty?、actualQty、lineNo | 差异记录；按 orderLineId 精确匹配（消除同物料多行歧义） |
| QualityCheck | receiptLineId、checkedQty、result、exceptionReason?、photoIds?、operatorId、checkedAt | — |
| PutawayRecord | receiptLineId?、subjectId、fromLocationId、toLocationId、quantity、recommendedLocationId?、operatorId、putawayAt | — |

### 库存账目
| 实体 | 关键字段 | 说明 |

| PhysicalInventory | locationId、subjectId、quantity、version | 唯一(库位+主体)；乐观锁 |
| StockLedger | txnGroupId、seq、subjectId、locationId、quantity(有符号)、balanceBefore、balanceAfter、reason、sourceDocType?、sourceDocNo?、operatorId、occurredAt | 只追加 |

### 支撑
| 实体 | 关键字段 | 说明 |
|---|---|---|
| Attachment | bizType、bizId、fileName、mimeType、path、size、uploadedBy、uploadedAt | — |
| PrintLog | bizType、bizId、templateCode、printedBy、printedAt | — |
| ImportTask / ImportTaskDetail | 两阶段导入 | — |
| Sequence | type、scopeKey、bizDate、lastNo | 编号服务序号表 |

## 四、关键规则
1. 唯一性：material.code、warehouse.code、location(warehouseId,code)、batch(materialId,batchNo)、order.orderNo、receipt.receiptNo、subject(warehouse,material,batch,status)、physical(location,subject)、sequence(type,scopeKey,bizDate)。
2. **收货行匹配优先 orderLineId**（扫标签 ol 提供）；仅按 materialId 匹配在"同物料多行"时歧义，需带 ol 或由前端选行。
3. 非批控物料用默认空批次（batchNo=DEFAULT）。
4. 流水只追加；物理库存带 version；收货/质检/上架同一事务。
5. 编号统一走 NumberingService（Sequence 表）。
