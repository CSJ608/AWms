# 术语对照表（草案 v0.1）

> 状态：**草案（2026-08-09，讨论中）**，第 1 批（设计批），供 D-04 界面规格与 i18n 使用。
> 原则：**内部概念（契约/代码/领域）与界面词分离**——契约仍用内部概念名（避免歧义），界面/i18n 用用户词。
> 本表是两者的桥梁。

## 对照表

| 内部概念（契约/领域） | 界面词（推荐） | 用户理解 | 备注 |
|---|---|---|---|
| 库存主体 | **库存** | 某一"物料×批次×状态"在仓库里共有多少（跨库位合计） | 状态用标签区分：待检/可用/冻结 |
| 物理库存 | **库位库存** | 某个库位里放着什么、各多少 | 备选：库存分布 / 存放明细 |
| 库存流水 | **库存流水** | 每一笔库存变动的记录（谁/何时/从哪到哪/为什么） | 备选：变动记录 |
| 可用量 | **可用库存** | 现在能发、能用的数量 | — |
| 内部批次号 | **批次号** | 系统给这批货的编号 | 与"来源批号"区分 |
| 来源批号 | **来源批号** | 供应商/生产那边这批货的批号 | — |
| 来源单据类型（ty） | **入库类型** | 这批货从哪来：采购入库 / 生产入库 / 其他入库 | 与"标签类型"区分 |
| 唯一码 | **唯一码** | 每件/每箱的唯一编号 | 备选：箱码（如按箱管理） |
| 库存主体状态 | **状态** | 待检 / 可用 / 冻结 | 已有语义色 |
| 收货单（执行单） | **收货单 / 收货回执** | 本次收货的记录与凭证 | 回执=打印给对方的版本 |
| 入库预建单 | **入库单** | 预先建的采购/生产/其他入库单 | 界面按类型显示：采购入库单 / 生产入库单 / 其他入库单 |
| 入库待办 | **待办** | 待质检 / 待上架 | PDA 与 Web 工作台 |

## 说明

1. 界面词只影响展示与 i18n key，不影响契约字段名与代码标识符。
2. 同一概念在不同语境可微调：如 PDA 上"库位库存"可简称"库位"（上下文明确时）。
3. 术语表随界面规格一起评审（D-04），定稿后进入 docs/product/ 标准区。
