# 路线图 v0.2（2026-08-10）

> 状态：随批次推进更新。批次边界可在门禁评审时调整。

## 目标与边界

- 内部原型，验证概念设计可行性；单组织、多仓库；SKU ≤ 10 万、日单据 ≤ 2000、用户 ≤ 50。
- 一线作业 PDA 优先；本期人工仓为主，预留 AGV。
- 路线从"收货 → 查阅收货库存"开始。
