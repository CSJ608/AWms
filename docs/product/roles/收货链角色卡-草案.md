## 角色 1：收货/质检/上架员

- **一句话职责**：用 PDA 把到货变成"已上架、可用、可追溯"的库存。
- **作业频率**：每天多次、连续作业；单次操作节奏快（秒级）。
- **痛点**：高频录入怕填错；单据多怕漏；数量/批次/库位靠记忆；异常（破损、差异、库位满）会打断节奏。
- **心智负担**：要记"这批货是什么、多少、放哪、有没有问题"；最怕做了一半发现前面填错了。
- **一个时段专注的一件事**：把眼前这一单货正确入库（收货 → 质检 → 上架一条龙），不要让他切换其他任务。
- **系统要为他做到**：
  1. 扫码/少输入完成全部动作，每步有校验，错了当场拦住；
  2. 状态一眼可见（待检/可用/待上架），下一步做什么系统直接引导；
  3. 异常一键上报（拍照+原因），不让他停下来找人。

## 角色 2：仓管/主管

- **一句话职责**：掌握仓库现状、处理异常、组织作业。
- **作业频率**：随时查看，高峰时频繁。
- **痛点**：账实不符说不清；待办/异常分散；要等现场反馈。
- **心智负担**：要回答"现在有什么待办、有什么异常、库存对不对"。
- **一个时段专注的一件事**：处理眼前这一批异常/待办（Web 上集中处理，不必到现场）。
- **系统要为他做到**：
  1. 工作台：待办（待质检/待上架/异常）与库存状态一目了然；
  2. 异常闭环：现场上报 → 主管 Web 确认 → 状态更新；
  3. 追溯：任何一笔变动可查流水、可看收货照片。

## 角色 3：系统管理员

- **一句话职责**：维护主数据（物料/仓库/库位/用户/角色）与权限。
- **作业频率**：低频，但集中在启用期。
- **痛点**：数据录入繁琐、配置分散、权限不清。
- **心智负担**：保证"数据对、权限对、模板对"。
- **一个时段专注的一件事**：把某一类主数据批量整理正确（导入导出 + 校验结果处理）。
- **系统要为他做到**：
  1. 批量导入导出（标准模板 + 预校验 + 失败明细）；
  2. 用户/角色/权限集中管理（路由+菜单+按钮三层）；
  3. 打印模板管理（后续：内置模板可用，配置界面后置）。

## 角色 4：拣货/发货员（占位，出库链时细化）

- 职责：按出库单找货、复核、发货；终端 PDA。
- 本期不做，角色卡在出库链设计批补充（含 AGV 执行主体预留）。
