## 一、问题与修复说明

**问题**：OPERATOR 登录后 `/auth/me` 返回 `menus.web` 4 项（应仅 inbound）。根因：`MenuDefinition` 种子未设 `RequiredPermissionCode`，`AuthService.BuildMenuTree` 中
`if (!string.IsNullOrEmpty(m.RequiredPermissionCode) && !permissions.Contains(m.RequiredPermissionCode)) return null;`
的条件恒不成立，所有菜单对任何登录用户都返回。

**修复**：`AWms.Infrastructure/Data/AWmsDbContext.cs` 菜单种子补 `RequiredPermissionCode`（只改后端数据种子与迁移，不改 docs/、不改 F-05）：

| 菜单 | RequiredPermissionCode | 说明 |
|---|---|---|
| `menu.dashboard` | （不设） | 所有登录用户可见的占位页 |
| `menu.inbound` | `route.inbound` | OPERATOR/SUPERVISOR/SYSTEM_ADMIN 可见 |
| `menu.master-data` | `route.master-data` | SUPERVISOR/SYSTEM_ADMIN 可见 |
| `menu.system` | `route.system` | 仅 SYSTEM_ADMIN 可见 |
| `pda.receiving` | `route.inbound` | 与 WEB inbound 同权限 |

`AuthService.BuildMenuTree` 过滤逻辑本身无需改动，种子补齐后按角色权限生效。
